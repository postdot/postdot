# ADR-086 — AGPL-3.0-only for Postbot

- Status: accepted
- Scope: Original project code and public release preparation
- Provenance: Explicit owner approval, 2026-10-11
- Related task: PROJECT-302

## Decision

License original Postbot code under AGPL-3.0-only, without an additional proprietary
edition or commercial license at this stage. Preserve third-party licenses and
notices. Keep the repository private until communication, installation and release
preparation are ready and the owner explicitly authorizes public opening.

## Consequences

The license permits compliant forks and commercial services; it requires the
applicable source and notice obligations, including source offers to network users
of modified versions. It does not guarantee upstream contributions, revenue or
recognition. No mandatory marketing badge or additional branding restriction is
introduced by this decision.

Contributors retain their copyrights and submit their original contributions under
AGPL-3.0-only. No assignment or commercial relicensing grant is requested. Future
relicensing would require adequate rights; it is not promised by this policy.

Use the official unmodified GNU license text in LICENSE and SPDX identifiers in
package metadata. Copyright attribution and third-party distribution preparation
are separate from selecting the license. Public positioning remains proposed.
