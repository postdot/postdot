# UX-385 — Global search presentation

Base: f97e824e0. Owner requested compact controls, stable geometry, a quieter dark
surface, no separator lines, an illustrated empty result and a project switch.

## Implementation

- Compact icon and keyboard shortcut header trigger; shared tooltip retained.
- Palette anchored near the viewport top with a stable, bounded result region.
- Dark surface uses the existing raised token; light surface remains unchanged.
- Removed search separators and replaced scope Select with a neutral labeled Switch.
- Search field has its own inset surface and a concise placeholder; footer shows
  navigation, open and close shortcuts. Scope row has separate breathing room.
- Dark switch thumb uses foreground contrast, rather than matching the track.
- Loading status occupies a reserved control row; result counts cannot move input.
- Empty results use shared Empty primitives and existing result illustrations.
- CommandDialog accepts optional content styling without changing other dialogs.
- Existing browser scenario covers switch scope, geometry across result/empty
  transitions, illustration, dark/light, narrow layout, keyboard navigation and
  local retry. Server search and permissions remain unchanged.
