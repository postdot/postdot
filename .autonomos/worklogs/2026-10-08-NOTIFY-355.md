# NOTIFY-355 — Installation SMTP administration

Base: `d7276e660`. Status: complete; full integration and container recovery passed.

The owner accepted configuration and test delivery from installation administration,
with encrypted database settings rather than requiring environment-only setup.

## Boundary

One installation-owned configuration serves authentication, invitations and
personal publication outcome alerts. Existing deployment settings are the initial
fallback only while no database settings exist. Saving a disabled database setting
never silently restores deployment delivery. Changes apply to future sends without
restarting. Existing in-flight SMTP effects cannot be recalled.

Only a current human instance administrator can read, save or test the settings.
The test recipient is the authenticated administrator's account address; there is
no arbitrary recipient field. Test acceptance means SMTP acceptance, not inbox
delivery. Unknown failures do not trigger automatic test retries.

## Implementation

A migration adds installation_email_settings. The complete payload is AES-GCM
encrypted using the existing installation encryption key with a separate cipher
domain and authenticated purpose. Credentials never appear in public responses;
only hasPassword is returned. Omission preserves the password, null removes it.
Concurrent saves are serialized before reading the retained password. Corrupt or
unreadable persisted settings fail closed at startup rather than falling back.

The application-owned service provides the current configuration to both existing
email consumers. Disabled delivery suspends outbox claiming/scheduling; enabling
replans durable pending work. The existing projection and effect executor remain
unchanged. Authentication callbacks resolve the configuration for each send.
Transport timeouts are bounded; logs never include raw SMTP errors.

The Configuration page has a single SMTP form using existing Field/Input/Switch
components. Settings are saved explicitly before testing. Deployment precedence,
password retention, TLS mode and SMTP acceptance are stated where relevant.
The form remains editable after failure. English and French copy is supplied.
