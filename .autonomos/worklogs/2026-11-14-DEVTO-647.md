- Decisions: Excluded `published_at` (conflicts with Postdot scheduling ownership) and raw `main_image` string (cover image remains governed by Postdot `media` + signed URL delivery). Never auto-defaulted `ai_disclosure_level` so it is omitted unless explicitly selected. Kept `published` optional in the schema (`true` at dispatch when omitted; explicit `false` creates a DEV.to draft) so existing v1 and untouched v2 channels still publish live. Added `{ id: 'tags', semantic: 'tags', path: '/tags' }` binding and `fieldId`/`errorId` forwarding on `BooleanField` `<SelectTrigger>` for accessible label binding.
