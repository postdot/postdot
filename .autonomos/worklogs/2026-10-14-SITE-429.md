# SITE-429 — Network marquee

The owner rejected SITE-428 as a visual regression and suggested an infinite horizontal marquee. Reviewed the live Vanta UI homepage: small app identities gain presence through depth and movement; demonstrations are composed rather than described. This is an inspiration source, not imported paid code or an endorsement of every effect.

Implemented one slow continuous plane with two equal SVG logo groups, soft edge masks, small raised logo surfaces and labels. Native pause/resume control, hover pause, offscreen/document-hidden pause and reduced-motion static grid. Duplicate content is hidden from assistive technology. No added package, claims or platforms. Preserve existing public typography, material and copy.

Validation: docs formatting and static build passed; desktop and mobile visual review completed. This is a proposal subject to owner judgment, not an accepted final network style. Isometric methodology remains a subsequent pilot; do not use this pass to invent more marketing sections.
