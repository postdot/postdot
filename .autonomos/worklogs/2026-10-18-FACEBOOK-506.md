# FACEBOOK-506 — Isolated Facebook Pages protocol

## Outcome

Added @postbot/facebook with metadata-only Page discovery and a bounded immediate publishing protocol. The owner approved this next pass after META-505. No OAuth app registration, channel profile, database connection route, worker adapter or Studio control is active yet.

Discovery reads one managed-Page batch using a user token. It returns canonical string IDs, Page tokens and tasks for server-side connection setup. A task-derived hasPublishTask flag is not a claim of full permission, app-review or destination readiness. Pagination returns an opaque cursor; it never follows provider paging URLs or automatically chooses a Page. Consumers must never serialize these credential-bearing objects to clients or logs.

Sends support literal text, an optional HTTP(S) link, or one inspected JPEG/PNG Blob. The photo endpoint accepts multipart bytes, avoiding a public URL requirement for this Facebook slice. Initial support deliberately excludes other provider-accepted image formats, videos and albums. Link plus photo is rejected rather than dropping an input. Photos use caption and optional alt_text_custom; deprecated message/name photo parameters are not used. The package does not invent a provider text-length limit or register a profile before native constraints are established.

Photo and post identities are distinct: require both photo ID and published post ID. Missing, malformed or mismatched publication identity is ambiguous. No internal write replay occurs. Structured 4xx Graph errors distinguish credential renewal, permissions, rejected requests and throttling. Valid bounded Retry-After seconds defer; unsupported hints require inspection rather than an early retry. Transport loss, 5xx, conflicting success/error envelopes, redirects and malformed replies remain ambiguous for writes; metadata reads can be retried safely. Errors are static and do not expose provider descriptions or exceptions. Tokens are opaque printable strings carried only in Authorization headers.

Pinned Graph v26.0 and fixed HTTPS origin. Updated workspace registration, lockfile, Docker manifest-only COPY inputs and narrow package AGENT.md. Existing runtime registrations are unchanged.
