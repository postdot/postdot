# TAXONOMY-129 — Implement the durable taxonomy foundation

## Objective

Implement the first bounded runtime slice of accepted ADR-062 without adding
an unreviewed UI taxonomy or provider-specific semantics.

## Delivered

- Added an additive SQLite migration for instance-scoped project categories,
  project-scoped publication tags, and composite project/publication/tag
  assignments.
- Added core normalization and validation: NFKC, Unicode whitespace collapse,
  locale-independent case folding, bounded Unicode length after normalization,
  opaque IDs, and active/archived lifecycle.
- Added project persistence for an optional primary category and updated every
  project read mapper used by authoring, channels, publisher credentials, and
  publisher execution.
- Added typed API routes for category CRUD/lifecycle, project assignment,
  project tag CRUD/lifecycle, and publication tag replacement/listing.
- Enforced project actor scope server-side, deterministic ordering, duplicate
  conflicts, archived-tag assignment rules, audit attribution, and composite
  foreign-key isolation.
- Kept instance category-definition mutations on the deliberate temporary
  human-session boundary documented by ACCESS-116/ADR-061; project bearer
  tokens are not accepted for instance scope.

## Intentionally deferred

The web surface is not part of this slice. Project context, Compose/publication
detail controls, and Queue filtering are tracked as TAXONOMY-130 so their
information hierarchy can be designed before exposing the new metadata.

## Verification

- `bun run format`
- `bun run lint`
- `bun run typecheck`
- `bun run test` — 139 API tests, 132 database tests, and 12/12 E2E scenarios
- `bun run build`
- Targeted API coverage for category/tag scope, duplicate normalization,
  publication assignment, and archived metadata retention.
- Targeted domain coverage for Unicode case-fold expansion that could otherwise
  exceed the database bound.

## Review outcome

An independent review found and the implementation corrected the normalized
Unicode length edge case. The temporary instance-admin boundary was confirmed
against ADR-061 rather than inventing a taxonomy-specific role.

## Protocol

This work is delivered through PR #187. No real provider credentials,
external-provider side effects, or production data were used.
