# UX-679 Post text and channel versions on the publication page

Outcome: The top editor is labelled "Post text, shared by every channel". A channel
version that publishes the post text as is follows it while typing (the preview no
longer lags); "Adapt for {channel}" says whether the channel follows the post or has
its own text, and a notice offers to take the post text again. "Draft kept" became
"Changes pending", the footer says what will be published is unchanged, and "Discard
changes" restores the applied version with an undo toast. Saving a post change keeps
sibling versions current when the change leaves them unchanged (db), so an undone
change leaves nothing behind. Locked publications show one centred preview. Language
fields use a searchable picker by name (BCP 47 stays internal).

A browser extension, not Studio, drew the orange badge in the owner's screenshot.
