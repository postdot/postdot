# OPS-192 — Integrate the audit branch and reconcile worktrees

- Date: 2026-09-22
- Status: complete
- Issues: [ISSUE-105](../ISSUES.md#issue-105-define-the-integration-state-of-the-external-audit-branch), [ISSUE-107](../ISSUES.md#issue-107-reconcile-branch-and-worktree-hygiene)

## Objective

Integrate the owner-selected committed branch without rewriting its history,
then reconcile worktrees and local branches without deleting user work or
touching remote refs.

## Actions

- Created a clean temporary worktree from `main`.
- Fast-forwarded `main` to `codex/reui-calendar-spike`.
- Removed 18 clean worktrees whose HEADs were ancestors of `main`.
- Pruned the missing `/tmp/postbot-review-discord` worktree metadata.
- Evaluated the two remaining non-ancestor commits before removal: the `7ae0`
  correction is already carried by `b0027ac5`, and the taxonomy patch is an
  exact duplicate of `c3df184a`.
- Removed `/home/hakim/.codex/worktrees/7ae0/postbot` and
  `/home/hakim/.codex/worktrees/taxonomy-130-backend` after focused tests passed.
- Removed the remaining old calendar MVP worktree
  `/home/hakim/Documents/Codex/2026-09-02/in-app-browser-context-source-ambient`
  after the owner confirmed that its untracked ReUI Calendar files were no
  longer needed.
- Audited every local branch against `main`. Forty-seven branches were already
  ancestors of `main`; their local refs were removed, excluding `main` and the
  checked-out `codex/reui-calendar-spike` ref.
- Evaluated the four non-ancestor branches individually. The taxonomy backend,
  SQLite posture, and Bluesky observations branches were exact patch duplicates
  of commits already in `main`. The Bluesky loopback branch was superseded by
  the integrated `ce962f20` implementation and its later access-policy work.
  All four local refs were removed; no remote ref was changed.

## Evidence

- `main` and `codex/reui-calendar-spike` both resolve to `f557a37b`.
- The integration preserved all 80 commits; no rebase, squash, or reset was
  used.
- The current checkout's 275 changed or untracked paths were not modified by
  the integration.
- `git worktree list --porcelain` now contains only the authoritative checkout.

## Validation

- `git rev-list --left-right --count main...codex/reui-calendar-spike` → `0 0`
- Focused workflow, taxonomy, API, client, and database tests pass: 61 tests.
- `git worktree list --porcelain` confirms that only the authoritative checkout
  remains.
- `git branch --merged main` and patch-id/content comparisons establish that no
  unintegrated implementation was removed.
- `git branch -vv` confirms that only the authoritative local refs remain from
  this cleanup; remote branches were not modified.
