# CLI-601 — Public CLI design

Status: complete
Completed: 2026-10-30

The owner delegates scope and architecture selection for the public remote CLI and explicitly retains Eden Treaty instead of rebuilding an HTTP client. Reviewed the existing script, transport package, API release metadata, release tooling and official tool documentation. The script already performs remote operations; distribution and operator experience are the missing product boundary.

Recorded the recommended design in SPEC-011 (draft, not silently promoted to a normative specification). Preferred Commander, a Node-targeted npm package built with Bun, the bundled existing Treaty factory, named origin-bound connection profiles, scoped API-key authentication, predictable machine output and independent CI/OIDC release. Authentication routes outside the Elysia type and deployed-server compatibility are separate concerns from build-time typing. First-alpha session-only administration, native binaries and a separately published SDK are explicitly deferred.

No application or CLI runtime code changed. Reviewed source links, identifier uniqueness and repository spelling for the design artifacts. CLI-602 is the recommended implementation/release task, beginning with an installed-package Node/Treaty/upload proof. No new AGENT.md rule is needed: packages/client already forbids duplicating API contracts. Unrelated authentication and task-history edits remain untouched.
