# FOUND-570 — Foundation dependency stability

## Authorization and scope

Owner accepted the recommended ISSUE-189 assessment after PROV-569. Prepare one
reviewable position for the foundation dependencies before release. Do not upgrade,
replace or silently accept architectural risk. Preserve the self-hosted boundary.

## Plan

1. Inventory installed, declared and production versions and actual source use.
2. Verify relevant upstream stability and compatibility evidence from primary sources.
3. Compare retain/pin/replace options, migration boundaries and acceptance criteria.
4. Present one recommendation for owner review, validate documentation and integrate locally.

## Findings and proposed result

Prepared ADR-092 as a proposed decision, not an accepted policy. It compares
retain/pin/replace options, identifies actual production coupling and names review
triggers and exit paths for all four foundations.

- Read exact installed package metadata and `bun.lock`; reviewed manifests,
  Docker stages, CI frozen installs, prototype route/imports, schema bridge and
  existing accepted runtime direction. Local Bun's full revision is canary even
  though its short version omits that qualifier.
- Queried primary npm dist-tag endpoints without installing packages. Elysia's
  experimental, beta, RC and stable tags differ across plugins. TypeScript 7.0.2
  is the current stable npm tag; TanStack DB remains upstream beta.
- Verified official release/migration notes. Bun 1.4.3 and 1.4.4 include security
  changes relevant to the runtime, so indefinite retention of 1.4.2 is not the
  recommended release position. No exploit or provider exposure was tested.
- Confirmed TanStack DB appears only in the development prototype and its tests;
  normal production features use Query. WEB-557 supplies the earlier production
  asset/browser proof, and current source retains the same exclusion.
- No repository-owned compiler-API import was found. The existing 21-task build
  evidence covers ordinary code/docs builds, not every possible Storybook or
  third-party compiler integration. The proposed batch retains TypeScript and
  does not claim all future tools support its unstable API.

## Recommended next step

Request one owner decision on ADR-092: qualify and align stable Bun 1.4.4, pin the
existing Elysia/schema tuple, retain TypeScript 7.0.2 and keep TanStack DB exactly
pinned in development. Run one final cross-cutting validation for the combined
runtime change. No global install, manifest/lockfile edit, dependency upgrade,
real-provider call, release or remote action was performed during this assessment.

ISSUE-189 stays open pending acceptance of the risk positions. FOUND-570 can close
when this reviewable assessment and documentation checks are complete. No new
AGENT guidance is appropriate before the proposed direction is accepted.
