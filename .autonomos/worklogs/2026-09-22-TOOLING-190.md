# TOOLING-190 — Standard repository spelling gate

- Date: 2026-09-22
- Status: complete
- Issue: [ISSUE-117](../ISSUES.md#issue-117-enforce-the-repository-language-boundary-and-vocabulary)

## Context

The former repository-language check was a project-specific regular-expression
scanner. It did not provide a standard spelling dictionary, reliable token
boundaries, or a reviewable way to distinguish technical terms from mistakes.

## Accepted approach

Use CSpell as the repository spelling gate. Scan code, tests, documentation,
configuration, and Autonomos artifacts in English. Exclude only translation
catalogs, generated localization output, standard generated/runtime paths, and
the reviewed project dictionary. Keep localized browser assertions inline and
explicit rather than excluding whole test files.

## Evidence

- `cspell@10.3.3` is a development dependency and is locked in `bun.lock`.
- `cspell.json` owns the scan scope, generated-path exclusions, standard
  dictionaries, and the reviewed project dictionary.
- `scripts/check-repository-language.ts` is removed.
- `bun run lint:spelling` and a cache-reset CSpell run pass.
