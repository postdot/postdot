## Export contract

Read all publication pages matching the selected current-tag AND filter, not only loaded UI pages. Retain the same published/supported-provider cohort as Performance. Use the existing latest stored observation endpoints in provider batches of 25. Never call collection endpoints. Reject incomplete observation responses or failed reads rather than downloading a partial report. Deduplicate publication IDs and detect repeated cursors rather than loop indefinitely. No report-wide transactional snapshot is claimed; reads reflect saved data during export.

CSV uses stable English machine-readable headers, CRLF records and UTF-8 BOM for spreadsheet compatibility. One row per supported metric and publication/destination. Preserve zero versus missing values, metric key, provider, unit, aggregation, availability, freshness, observed and fetched ISO UTC times. An uncollected expected metric has blank value/times and explicit not_collected availability; unavailable values stay blank, not zero. Include project/post/publication/channel identity, source title, external identity/link, publication time, selected current tag IDs and export time. No sum, collection or inferred historical attribution.

Quote cells and double embedded quotes. Neutralize spreadsheet formulas in text beginning with formula/control characters, including leading whitespace before =,+,-,@, without altering numeric metric values. Cancellation or project/filter changes discard an in-flight result before download. All project members retain existing read access; export grants no refresh capability.

Worker owns only apps/web/src/lib/publication-performance-export.ts and its focused test file. Parent owns the page, messages, browser scenario, governance/docs/config/integration/cleanup. No shared servers, browser/E2E, real credentials/provider effects, network, nested agents, main writes, merge/push or hook bypass. Local deterministic helper tests and isolated static checks are permitted with safely owned dependency directories. Stop after a bounded candidate/report or exact blocker.
