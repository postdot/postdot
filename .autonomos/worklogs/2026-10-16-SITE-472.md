# SITE-472 — Branded static social previews

## Completed

Reviewed the existing Solar Icons ImageResponse/template approach. Added a Postbot
composition using the existing mark, duotone wordmark, Host Grotesk and blue pigment
field. The homepage uses its existing headline; documentation uses its own title,
description and audience-space label. No new positioning copy or public release
claim was introduced.

The field is a deterministic CPU snapshot of the public shader's palette/formula,
with a neutral fade and fixed pixel grain. It is generated during content sync.
All social images are statically exported. Added metadata for homepage/docs,
configurable POSTBOT_SITE_URL with a local preview default, and an export gate.
Kept noindex unchanged. No images or repository content were published externally.

## Findings and verification

- The variable UI font failed in the OG font parser. Added build-only Fontsource
  static Host Grotesk 400/600, matching the surrounding project's approach.
- Initial raster inspection exposed unsupported inset positioning. Explicit
  top/left removed the gap; softened the field behind longer text.
- Visually checked homepage, first-publication and API title samples, including
  the longest current API heading. No truncation or title clipping observed.
- Static build passed: 181 distinct 1200 by 630 OG PNGs, matching metadata;
  787 local links and all 180 Markdown exports remain valid.
- Quick repository gates passed; PNG chunk term IDAT added to spelling dictionary.
- Total OG output is about 77 MB; individual previews are roughly 400 KB. These
  are static sharing assets and are not bundled into normal page content.
- Restarted only the local docs preview on 5174 after finding it unavailable.
  The application integration test remains deferred at the owner's request.
