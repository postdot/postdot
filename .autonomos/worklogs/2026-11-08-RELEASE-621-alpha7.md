## Features shipped in 0.1.0-alpha.7

- **PostgreSQL persistence**: Full support for PostgreSQL 16 and 17 as an alternative to SQLite via `POSTDOT_DATABASE_URL`, with cross-engine schema parity, portable SQL migrations, and dialect abstraction (`DB-609`, `DB-610`, `DB-611`).
- **Multi-server topology**: Instance coordination and advisory-lock worker distribution across multiple Postdot API instances backed by PostgreSQL (`DB-612`).
- **S3 storage profiles**: Store uploaded media in AWS S3 or compatible object storage (Cloudflare R2, MinIO) via `POSTDOT_STORAGE_PROFILE`, alongside local filesystem storage (`DB-613`).
- **Database & media transfer**: Built-in transfer utility to migrate data between SQLite and PostgreSQL, and between local disk and S3 media stores (`DB-613`).
- **Worker reliability & capacity**: Resilient publication worker scheduling with missed wakeup recovery, bounded query planning under high volume, and automatic claim release after conflicts (`DB-614`, `PERF-615`, `DB-616`, `PERF-617`, `DB-618`, `PERF-620`).
- **Spanish and German localizations**: Complete interface localization with lazy-loaded translation bundles and 100% i18n coverage (`ISSUE-162`, `ISSUE-193`).
- **Command palette shortcuts**: Enhanced quick search with global shortcuts for publication composing and navigation.
- **Production deployment guides**: Qualified Kubernetes, Docker Swarm, and reverse-proxy guides (`ISSUE-161`).
