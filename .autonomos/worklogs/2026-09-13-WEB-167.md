# WEB-167 — Add a focused calendar keyboard navigation pilot

## Status

Complete.

## Owner direction

Introduce useful reading shortcuts carefully, scoped to the calendar rather
than creating a global keybinding layer that could interfere with forms and
future screens.

## What changed

- Added the TanStack `@tanstack/react-hotkeys` and `@tanstack/hotkeys` packages
  to the web workspace.
- Registered `T` for Today, `M`/`W`/`D`/`A` for Month/Week/Day/Agenda, and
  `[`/`]` for the previous/next period on the calendar shell only.
- Reused the calendar's existing navigation and view callbacks, so keyboard
  actions follow the same URL and history policy as pointer actions.
- Ignored editable controls, stopped propagation after a match, and disabled
  the pilot while the publication preview is open.
- Added `aria-keyshortcuts` metadata to the corresponding controls without
  adding a permanent explanatory block to the interface.

## Evidence

- The integrated browser focused the Month control, pressed `W`, and reached
  Week with the expected `view=week&date=...` URL.
- Pressing `]` advanced the focused week and date while keeping the calendar in
  place; reloading restored that state.
- The populated browser scenario covers the keyboard view/date path and the
  existing pointer, responsive, dense-cell, and preview behavior.
