## Objective

Provide a durable publication editor that preserves work during continuous editing,
exposes the channel contract and validation feedback, protects shared source content
with optimistic concurrency, and promotes an explicit validated snapshot without
mutating the selected delivery target during autosave.

## Delivered

- Added a database editor state spanning the publication, shared source post, channel,
  selected channel profile, mutable working draft, and immutable selected target.
- Added publication summaries for the dashboard, including draft revision, review
  state, and whether the working draft differs from the selected target.
- Added authenticated API routes to list publications, read editor state, save a
  working draft, and explicitly promote it to a new target revision. OpenAPI documents
  all route contracts and conflict responses.
- Added draft and promotion compare-and-swap checks. Draft revision and shared post
  source revision both fence writes, so concurrent editors cannot overwrite newer
  source content or intermediate draft state.
- Kept autosave separate from delivery: a draft update never changes the selected
  target revision, pending job, schedule, or execution snapshot. Promotion performs
  validation, media resolution, target revision creation, and scheduling changes in
  one transaction.
- Added media capability assessment to unscheduled draft creation and autosave. A
  missing asset, unavailable representation, incompatible format, missing public URL,
  or other media constraint is persisted as `review_required` feedback while the
  draft remains editable.
- Added a React 19 and TanStack Router publication editor with source fields, exact
  target JSON editing, capability summaries, validation issues, explicit scheduling,
  and selected-target visibility.
- Added versioned local recovery storage for source content, target JSON, and schedule
  state. Recovery handles disabled/full storage, keeps the latest server revision as
  the conflict base, and offers either server reload or local restoration against that
  latest revision.
- Added the editor route to the generated TanStack route tree and linked publication
  summaries from the dashboard.
- Kept the implementation on Base UI and Solar Icons Linear conventions; no Radix
  primitives or second server architecture were introduced.
