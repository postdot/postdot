# CHANNEL-490 — Structured mapped-request controls

## Implementation

Integrated ChannelRequestBuilder into ChannelContentBuilder for existing custom mapped HTTP profiles. Method and static path segments are editable; dynamic/secret segments are read-only, labeled as preserved. HTTP outcome classifications sit behind disclosure. Body, query/header maps and response extraction remain untouched and explicitly outside this form's editing scope.

Added an atomic outcomes edit to the preservation adapter. All four draft code lists are parsed strictly and applied together only when valid and disjoint, allowing code reassignment without publishing an intermediate classification. Local invalid drafts remain visible and propagate invalidity to the parent save/create controls. Input errors include accessible associations. Added English/French messages.

Added a reusable isolated Storybook example with the real component and a local-only profile. No custom mapped creation template, execution conversion, HTTP test request or secret input was introduced.
