# MEDIA-28 — Signed public media delivery URLs

- Date: 2026-08-31
- Status: completed
- Task: [MEDIA-28](../TASKS.md)
- Related specification: [SPEC-004](../specs/SPEC-004-publication-content-boundary.md)
- Related decisions: [ADR-019](../decisions/ADR-019-separate-media-assets-representations-and-deliveries.md), [ADR-022](../decisions/ADR-022-use-expiring-signed-media-delivery-urls.md)

## Objective

Give declarative custom HTTP mappings a safe URL representation for immutable media
without exposing storage locators, requiring public storage ACLs, or coupling media
delivery to Better Auth sessions.

## Delivered

- Added a stateless, versioned HMAC-SHA-256 media URL authority with bounded,
  deployment-configured expiry.
- Added a dedicated `HERALD_MEDIA_PUBLIC_URL_SECRET`; it is separate from Better Auth,
  publisher credentials, and channel connection secrets.
- Added an unauthenticated public route that resolves only signed project, asset, and
  representation identities and streams only ready media through the `MediaStore`.
- Made deleted, missing, expired, malformed, cross-project, and otherwise ineligible
  media resolve to the same not-found response.
- Added verified response metadata, private no-store caching, referrer protection,
  and content-sniffing protection to the public media response.
- Connected the application-owned URL authority to the custom HTTP `media_urls`
  expression. The generic transport receives URLs and never constructs storage URLs.
- Preserved multipart delivery as an alternative for receivers that do not need an
  independently fetchable URL.
- Added the explicit application composition capability required before a profile
  that declares `publicUrlRequired` can be promoted.
- Updated the configuration example, README, footprint fixture environment, and
  related media specification/decision records.

## Deliberate limits

- The capability is a bearer URL and can be replayed until expiry; there is no
  per-URL database ledger.
- Public URLs are generated only by the application composition that owns the
  signing authority. Storage adapters do not expose presigned or backend URLs.
- URL mappings remain one bounded request and cannot execute scripts or arbitrary
  transformation code.
- URL delivery requires the representation to remain ready and retained. Receivers
  that process media after the URL expires must copy it during delivery or use
  multipart delivery.
