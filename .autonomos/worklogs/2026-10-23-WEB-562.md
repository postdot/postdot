# WEB-562 — Project member and invitation contracts

ProjectInvitationStatus from Eden server responses in the client package.

re-exported the types through the existing web module. Editor/viewer write
inputs and normalized ApiError handling remain intact. Thirteen compile-time
assertions cover result envelopes, roles and closed invitation/member states.
