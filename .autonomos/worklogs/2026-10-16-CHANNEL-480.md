# CHANNEL-480 — Structured content controls

## In progress

Production browser adapter projects direct text/media bindings, makes guarded
targeted edits and retains the original definition. No TypeBox compiler is
introduced into the browser bundle; the API remains the validation authority.
Unsupported composed/referenced rules, relations, provider-owned execution and
inconsistent dual bounds are read-only. Per-family constrained media is also
read-only rather than applying misleading global edits.

Seven focused tests (30 assertions) passed against real templates and the core
compiler. These include sibling references, media count, formats and preserved
independent constraints. UI integration and browser verification follow.

## Delivered UI and evidence

Shared rules form replaces the creation/profile JSON textarea. Text presence,
maximum and accepted formats, media families, maximum count and global file size
are editable on supported profiles. All other definition data is retained.
Unknown profiles show preserved/read-only rules rather than an editable fiction.
Preview reuses TargetFieldControl and never calls a delivery/media API.

Browser verification on the local project created a clearly named manual test
channel (no publisher), using a 500-character message, required title, two images
and a 5 MB file limit. Reopening retained all settings. Saved drafts at 600 then
700 characters, assessed impact, confirmed that another edit invalidated the
assessment, explicitly activated and reopened the 700-character active profile.
An empty maximum disabled creation/save; correction restored the controls.
The manual test channel was archived afterwards; no publication was sent.

At 390×844, the dialog's content and scroll widths both measured 341 pixels, with
vertical scrolling and the preview below the rules. Added title clearance for the
close button after checking this viewport. Restored browser viewport afterwards.

The older Studio dev process exited during verification. API readiness stayed
healthy; restarted Studio with the documented Bun/native Vite command and
continued. No lock cleanup or data repair was needed.

Validation: 16 focused tests / 87 assertions, web typecheck and production build
passed. Commit hook runs repository quick gates against the final tree.
