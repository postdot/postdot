# QUAL-38 — Repair the documented Bun coverage command

- Date: 2026-09-02
- Status: in progress
- Scope: root test scripts and coverage documentation
- Task: QUAL-38
- Issue: ISSUE-017

## Objective

Make `bun run test:coverage` execute the Bun unit and integration suites without
loading Playwright specifications, while keeping browser integration coverage in
its dedicated runner.

## Context

The previous script invoked `bun test --coverage` from the repository root. Bun
discovered `e2e/publication-media.spec.ts`, whose Playwright `test()` calls are not
valid when loaded by Bun's test runner. The regular `bun run check` gate was already
green because it runs package tests and Playwright separately.

## Change

- Added Bun's `--path-ignore-patterns='e2e/**'` to the root `test:coverage` script.
- Documented that coverage covers Bun unit/integration suites and that Playwright
  remains a separate `test:e2e` command.

## Validation

- `bun test --coverage --path-ignore-patterns='e2e/**'`: 222 tests passed across 39
  files, with text and LCOV reports generated.
- The commit hook ran the full `bun run check` gate successfully: formatting, lint,
  strict typechecking, unit/integration tests, browser integration, and builds.

## Boundary

This task does not change test selection for the normal quality gate, coverage
thresholds, or the distinction between Bun and Playwright runners.
