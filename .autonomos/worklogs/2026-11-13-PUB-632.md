# PUB-632 Thread authoring

Outcome: X, Bluesky and Mastodon have destination-native thread editing, ordering,
per-message limits, preview and durable delivery/review. Existing profiles remain
historical; using the new capabilities requires explicit template/draft adoption.

Decisions: The shared source remains the first message. Postdot bounds a thread
at 25 messages; continuations are text-only and the root owns media, polls/cards.
Immutable execution/position receipts retain provider IDs and Bluesky CIDs. A
partially public failure records an effect, never a false no-effect fact. Known
rejections can resume; unknown writes stop until the exact message is reviewed.
Started versions stay locked. Mastodon requires explicit visibility for the whole
chain to avoid leaking replies through different account defaults. Native modules
own receipt and continuation rules; persistence owns transactions and scope.
