# ANALYTICS-633 Performance delivery dashboard

Outcome: Performance exposes saved delivery history with rolling periods,
comparison, destination filtering and an interactive daily chart. Engagement
remains a separate saved-data workflow with its existing tags and CSV scope.

Decisions: The server anchors relative windows so browser clock skew cannot ask
for future data. The previous window has the same duration; daily buckets retain
the project timezone, including partial edge days. Historical outcomes can overlap
after recovery, so they are not presented as mutually exclusive queue states.
An unavailable comparison never hides a valid current report; incomplete coverage
suppresses comparisons. The analytics client preserves JSON civil dates because
Eden otherwise turns bucket keys into Date objects and the chart loses its keys.
Export fixture isolation leaves the old live page before strict filtered-read
assertions: the captured unfiltered request preceded the tagged navigation, not
its export. No assertion was relaxed. Native HTML keeps the chart dependency-free.
