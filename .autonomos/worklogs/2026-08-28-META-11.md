# META-11 — Keep the IDE Workspace Synchronized

## What was done

- Added the existing `apps/api`, `apps/web`, `packages/auth`, `packages/core`, and
  `packages/db` directories as named folders in `herald.code-workspace`.
- Added durable root guidance requiring the workspace file to be updated in the same
  change whenever an app or package is added, removed, or renamed.

## Decision

`herald.code-workspace` is a maintained monorepo navigation artifact. Its folder list
must match the direct project directories under `apps/*` and `packages/*`, while the
root Herald folder remains available for repository-wide files.

## Validation

- The workspace folder paths exactly match the repository root plus every current
  direct child of `apps/` and `packages/`.
- `git diff --check` passes.
