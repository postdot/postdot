# CHANNEL-486 — Share composer count rendering and constraints

## Findings and changes

The preview already mounts the real PublicationTextEditor and MediaAttachmentPicker. The paperclip is defined once in MediaAttachmentPicker, so changing it affects both New publication and the preview. The emoji picker and composer appearance are shared too. The complete New publication page is not mounted in a configuration dialog: provider-specific configured editors, scheduling, social previews and persistence are outside this local sample.

The counter was duplicated and the preview only considered maximum characters. Extracted PublicationTextCount from New publication, then reused the real constraint lookup and countComposerText in the preview. Both now render the same character/grapheme counter and use the same minimum/maximum evaluation. Draft profile lookup accepts unknown input with guarded capability access, avoiding an unsafe assertion that an unsaved definition is a validated domain object.
