# CLI-369 — Machine publication workflow

Base: `d49ce981b`. Local main, no push or provider side effects.

## Implementation

Added source-post creation, paginated publication listing, editor inspection,
draft save, revision-guarded promotion, batch schedule/cancel, and failed automatic
retry to the Bun CLI. Existing manual publish/reconciliation semantics remain.

Reviewed official Elysia Eden Treaty, Eden Fetch, and OpenAPI documentation.
Kept the existing `@postbot/client` Treaty factory: it already derives routes and
request types from Elysia. No generated SDK, extra dependency, handwritten HTTP
route for the new operations, or duplicate validation schema was introduced.
Untrusted file/stdin JSON is a deliberate type boundary; Elysia remains its
runtime validator. Existing response handling uses declared response DTOs where
Treaty's installed route response type includes an unknown fallback.

Added bounded file/stdin input, a 30-second transport deadline, machine-readable
stderr failures with API codes/status, and no automatic write retries. Eden's
synthetic 503 without a Response is distinguished from a real HTTP 503. Network
uncertainty is surfaced, not treated as a confirmed failed mutation.
