# CHANNEL-25 — Versioned channel profile lifecycle

- Date: 2026-08-31

- Related decision: [ADR-021](../decisions/ADR-021-channel-owns-profile-contract.md)

## Objective

Persist immutable channel profile versions, support editable drafts with optimistic
concurrency control, preview their impact on persisted work, and activate them without
rewriting publication content or execution history.

## Delivered

- Added draft, active, superseded, and disabled profile states with one active version
  and one draft per channel enforced by partial unique indexes.
- Added profile revisions with compare-and-swap writes for draft updates and activation.
- Added deterministic profile comparison and actual-instance assessment in `@herald/core`.
  Assessments cover structural schema validation, field bindings, capabilities, media
  representations, and automatic execution-contract changes.
- Kept working drafts on their selected profile while recording the profile version
  used for the latest assessment. Existing target revisions remain pinned to their
  original profile and content.
- Revalidated affected work atomically during activation. Review-required targets are
  prevented from automatic execution by cancelling their pending jobs; compatible
  automatic targets without a job receive durable execution work when a publisher is
  available.
- Added profile state, draft, preview, and activation endpoints to the authenticated
  Elysia API with OpenAPI response contracts and typed client helpers.
- Added the migration for profile drafts, assessment pointers, assessment issue data,
  and the relaxed scheduled-publication check required for review gating.
- Added focused core, database, API, migration, media, concurrency, and activation
  coverage without changing the existing provider or media ownership boundaries.
