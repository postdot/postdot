# UX-658 Queue: per post by default, channel marks, short dates

- Outcome: The queue lists a post once with its channels by default; a visible "Per post / Per channel" switch replaces the unlabelled menu (`?view=channels` for the per-channel table). Every row shows its channel mark, and grouped rows keep the post title for assistive technology. Dates omit the current year everywhere `formatProjectDateTime` is used. Grouped counts say "channels".
- Decisions: ADR-103 §3, §7. Q4 (undo after "Mark published", history tab) needs an API able to revert a manual publication record; not faked client-side. Q5/Q6 (hide empty filters, two-line mobile rows) remain.
- Validation: `bun run check:quick`; date-time unit tests; queue, overview, outcome and approval specs against the production build. `realtime-validation` notification body and `publication-detail-actions` local recovery fail on text the server or editor produces independently of this change.
- Open: Q4–Q6 → UX-662.
