## Key Decisions
- Use `drizzle-orm/bun-sqlite` at runtime and keep Drizzle Kit for migration
  generation. Drizzle Kit's SQLite apply command requires another driver, so
  migrations are applied through Drizzle's Bun migrator instead of adding an
  unnecessary SQLite runtime dependency.
- Keep Better Auth configuration injectable through `createAuth(database)` and
  keep HTTP mounting in `apps/api`.
- Configure shadcn with Base UI and the `render` composition pattern. Radix UI and
  Lucide are not part of Herald's web foundation.
