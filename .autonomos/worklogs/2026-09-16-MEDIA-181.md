- Status: Complete for the deterministic local validation slice

## Objective

Prove the end-to-end scheduled publication lifecycle without cloud credentials
or external provider side effects: scheduler wake-up, local provider delivery,
retry, cancellation, terminal failure, and ambiguous outcome.

## Delivered

- Added an optional `SchedulerTimers` seam to the publication worker so the
  scheduler can be driven deterministically in tests while production keeps
  the native timers.
- Added a local `Bun.serve` provider sandbox to the worker suite. It exercises
  successful delivery, `429` retry and eventual success, `400` failure, and
  `500` ambiguous delivery through the real custom HTTP transport and durable
  publication state transitions.
- Verified that cancelling a future publication before the scheduler wakes it
  prevents delivery and preserves the `cancelled` state.
