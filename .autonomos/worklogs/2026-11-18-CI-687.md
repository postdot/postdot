# CI-687 Production-build browser shards and balancing (ISSUE-206)

Outcome: CI browser shards now build `apps/web` once per shard and run Playwright against `vite preview` (`POSTDOT_E2E_PRODUCTION_WEB=true`) across 5 weighted shards (`PWTEST_SHARD_WEIGHTS: '57:56:59:43:45'`) with `fullyParallel: true` and `workers: 1`. Development-only editor lab specs (`e2e/editor-experiment.spec.ts`, 6 tests) run in a dedicated `e2e-dev` (`Browser tests (editor lab)`) job so coverage is preserved without delaying production shards.

Decisions:

- Keep `workers: 1` while setting `fullyParallel: true` in `playwright.config.ts` so Playwright splits individual tests across shards instead of clumping multi-test files (`publication-concurrent-editing.spec.ts`, `editor-composer-pilot.spec.ts`), while staying strictly sequential per shared API/database runtime.
- Skip `e2e/editor-experiment.spec.ts` only when `POSTDOT_E2E_PRODUCTION_WEB=true` (`/editor-lab` redirects to `/` outside dev) and run it in a separate `e2e-dev` job included in `verify`.
- Build `apps/web` inside each shard (~7s locally) rather than adding `needs: static`, avoiding the ~4.2m wait before `e2e` starts.
- Add `PWTEST_SHARD_WEIGHTS: '57:56:59:43:45'` across 5 shards so the back-heavy alphabetical test durations and shard 1's password-reset test (~41s) balance near the mean.

Measurements (baseline vs local production & CI):

- Baseline `main` CI run `44353356229` (`484c79041`, 4 dev-server shards): round ~17m 32s; `Static` 4m 11s, `Postgres` 7m 50s, `Recovery` 1m 47s, `Browser 1/4` 15m 55s (step 14m 28s + reset 41s), `2/4` 16m 10s, `3/4` 16m 49s, `4/4` 17m 11s.
- Local full production profile (`POSTDOT_E2E_PRODUCTION_WEB=true`, 4 shards): 260 passed, 6 skipped (`editor-experiment`), total test sum 1377.4s (23.0m). Equal-weight 5-shard simulation skewed 1.37x (376.8s vs 223.1s mean); weighted 5-shard (`57:56:59:43:45`) balanced to 275-287s per shard (1.023x max/mean).
- Targeted local verification after final config changes: `e2e/editor-experiment.spec.ts` on dev server 6/6 passed (43.6s); `e2e/anonymous-loading.spec.ts` + `e2e/release-identification.spec.ts` with `POSTDOT_E2E_PRODUCTION_WEB=true` 3/3 passed (22.3s).
- PR #46 CI run `44408936164`: browser shards 5m21s to 7m51s (1/5 5m21, 2/5 6m20, 3/5 5m32, 4/5 6m19, 5/5 7m51), editor lab 1m45s, static 4m20s, PostgreSQL 8m18s; round about 8m25s against about 17m30s, now set by the PostgreSQL unit tests.
