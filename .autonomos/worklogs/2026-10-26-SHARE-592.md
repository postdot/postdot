## Destination-safety prerequisite implementation

The source now holds automatic publications when a known destination changes.
This is a prerequisite within SHARE-592, not delivery of channel sharing.

- Migration 0020 adds four columns without rebuilding tables or resetting data:
  monotonic channel generation, retained non-secret channel identity, publication
  confirmation generation and immutable execution destination snapshot.
- Connection replacement compares provider/account/destination identity and a
  SHA-256 endpoint fingerprint. The public endpoint origin is retained for
  intelligible identity; URL credentials, paths, fragments and query strings are
  excluded. Tokens are not captured.
  Same-account token renewal and display-name changes do not invalidate work.
  First connection preserves existing pre-connection scheduling semantics.
- Scheduler selection, claiming and external-effect admission check confirmation.
  A claim taken before reconnection returns to pending without changing its
  selected target or requested schedule. Execution resolution refuses a newly
  substituted account after pinning; a request already using the original
  connection can record its original outcome.
- Explicit confirmation checks the live generation and selected target, project
  authority, connection and lifecycle state. It preserves content, approval and
  scheduling. Replacing a pending retry creates a new job and preserves the old
  immutable execution; the confirmation fact links both jobs. Failed work still
  requires its normal explicit retry action. Historical rows without captured
  identity remain unrecorded, rather than being backfilled with today's account.
- API reads are project-scoped; confirmation requires editor authority and the
  publication:dispatch API capability. Stale generation/target returns 409.
  Client types derive request bodies from the API route contract.
- Studio shows the changed account and actual selected content, separately from
  newer unapplied draft edits. Confirmation explains that scheduled/overdue work
  may resume unchanged. History, translations, conflict recovery and realtime
  invalidation are included. Public channel guidance distinguishes source builds
  from the unchanged alpha.2 image.
