# DOCS-567 — Port apps/docs to TanStack Start on Cloudflare static assets

## Outcome and decisions

`apps/docs` was converted in place (no sibling app, compatibility layer or cutover:
the Next site was never deployed). TanStack Start prerenders every page to
`dist/client`; `wrangler.jsonc` serves it as Workers static assets with
`drop-trailing-slash` and `404-page`, and has no Worker script. Reference was the
solar-icons.dev port; only the parts that apply to a never-deployed static site
were reused.

- Fumadocs uses the macro API (`async: true`); `vite.config.ts` dedupes Fumadocs and
  React. Bun installs several copies of `fumadocs-core`, so `tsconfig.json` maps
  `fumadocs-core/*` to one copy; without it page data types collapse to `PageData`.
  `@tanstack/react-router` must match the version `@tanstack/react-start` resolves
  (1.170.46), otherwise route `server` options lose their types.
- Markdown, `llms.txt`, `llms-full.txt` and the search index are prerendered server
  routes with explicit output paths; URLs are unchanged.
- API reference pages need their operation fragment in the browser. A static server
  function caches the result as JSON at prerender time and the browser reads it on
  navigation (verified: client navigation, fragment fetched, no reload).
- OG images are rendered by `scripts/generate-og-images.tsx` (satori + resvg) into
  `public/og`, replacing `next/og`. The theme script is rendered in `<head>`; the
  provider alone left no pre-paint script in the prerendered HTML.
- `scripts/build.ts` fails when the prerenderer logs `Error in render`, which it
  otherwise reports with exit code 0. `check:*` read `dist/client` and resolve
  `path.html`. The preview is `wrangler dev`.
- Skills added: tanstack-start-best-practices, wrangler. Official TanStack skills
  load on demand with `bunx @tanstack/intent list`.
- Left unchanged: robots/noindex (site unpublished), no deployment or domain work,
  brand wordmark (BRAND-551).

## Validation

- Full `bun run build` passed (203 pages, 885 local links, 199 Markdown exports,
  200 OG pages, zero prerender errors). `tsc`, oxlint, oxfmt, cspell passed.
- Served with `wrangler dev`: `/docs/x/` redirects to `/docs/x`, unknown path gives
  404, content types correct. Home page matched the Next export on height, images,
  sections and text length; theme toggle persisted and static search returned results.
- Not done: pixel-level comparison, Lighthouse, Docker image (no manifest change).
