# UX-655 One navigation, with COPY-653 user vocabulary

- Outcome: One sidebar with a product state (Overview, Queue, Performance; Channels, Media, Tags, People, Project settings; workspace channels) and a settings state opened from its foot that starts with one return row naming the project. The header keeps scope, search, notifications and the account menu; theme and language moved into that menu and into personal settings. Project time zone and archiving moved to a new Project settings page; invitations merged into People (`/invitations` redirects). Sign-in 401 now says the email or password is incorrect. 183 catalog keys rewritten in en/fr/es/de to the ADR-103 glossary (post, channel, content rules, scheduled, by hand, platform setup, system; French uses the native word for workspace).
- Decisions: ADR-103 §4 refined to describe the two sidebar states and "one concept, one page". Language names are native constants, not catalog keys. Browser specs keep their contract but use `switchTheme`, `openLanguageMenu` and `signOut` helpers in `e2e/locale.ts`; centred-title and return-button assertions were rewritten to left alignment and no return.
- Validation: `bun run check:quick` passed (100% i18n coverage). Focused Playwright run against the production build in progress at commit time; failures are fixed in follow-up commits.
- Open: COPY-653 remainder (plural keys such as "Schedule N publications", remaining jargon in publication and channel pages) continues with UX-657/659/660.
