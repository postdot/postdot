## Changes

- Replaced Postbot's approximate X weighted-text parser with the upstream v3 parser and invalid-character helper. NFC normalization, blank-text rejection, and the 280 weighted-character limit remain explicit at the provider boundary.
- Added provider-owned profile validation adapters to the shared profile compiler. The API composition root registers the X adapter; generic core contains no X parser dependency.
- Versioned the X channel profile to v2. It uses a high raw resource ceiling rather than a false raw-280 limit, and declares the weighted limit and algorithm identifier.
- Kept previously stored v1 profile snapshots unchanged while adapting their runtime schema and capabilities for the official weighted rule.
- Applied the X rule before persistence and scheduling, during draft promotion, and again in the delivery worker.
- Added localized live counts for the new-publication source, X-specific channel overrides, and the publication target editor. Existing v1 X profiles receive the same authoring treatment.
- Added upstream-behavior tests and API/browser integration coverage.
