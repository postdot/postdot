# CLI-602 — Public CLI implementation and release

Status: in progress

Owner corrects the initial Node-primary design: Bun is the primary runtime; Node compatibility is welcome, and existing standalone compilation can embed Bun. Updated the draft SPEC-011 accordingly. Official Bun compiler documentation distinguishes stable standalone compilation from experimental AOT; PR 45631 was merged on October 27. No wait for future runtime trimming or AOT is required.

Start with the distribution boundary and real remote calls, including upload. Commander is responsible only for the command grammar and help; configuration, workflow handlers, output and future prompts remain separate. Initial qualification is not a complete public release. Preserve the legacy script and all unrelated authentication work.

Implemented the first distribution slice in `packages/cli`: Commander command grammar and per-command help, inferred Treaty results, bounded request deadlines, structured errors, and project discovery/media policy/upload handlers. Bun builds a standalone executable and a self-contained JavaScript package. Portable file-backed Blob upload works under both Bun and Node without a second API transport. Copied source license and bundled Commander/Eden notices into the npm distribution. The root workspace list, lockfile and Docker manifest inputs include the new package.

Installed the actual local npm tarball outside the checkout and exercised it against an isolated real API/database with scoped credentials. Project discovery and byte-for-byte image upload pass under Bun JavaScript, the standalone Bun executable with no runtime on PATH, and Node JavaScript. Help requires no network or credentials. The local Linux x64 executable is about 105 MiB; bundled JavaScript is about 53 KiB. No cross-platform support or AOT performance claim is made. The Node shebang is specific to the npm JavaScript compatibility entry point; it does not define the primary native execution runtime.

The fresh production container image builds successfully with the new workspace manifest. Package/root TypeScript, focused grammar checks, formatting, lint and spelling pass. During qualification the command parser rejected trailing global options until positional-option mode was removed; acceptance then exposed incorrect fixture assumptions about the existing media response (`ready`, nested `media.asset`), which were corrected from the actual API contract. The remote upload check verifies the server-stored image bytes.

Not yet a public CLI release: profiles/credential persistence, the remaining publication command inventory, cross-platform qualification, release artifacts/notices and Changesets/OIDC wiring remain within CLI-602. No npm or GitHub publication was attempted. Next implement origin-bound profiles and migrate the publication handlers through the same inferred Treaty boundary.
