## Actions completed in this reconciliation

- Added `scripts/check-repository-language.ts` and wired it into the root lint
  gate. It scans repository text artifacts while excluding translation catalogs,
  generated localization output, build output, dependency trees, and other
  generated data. The pre-commit hook uses `check:quick` so it does not launch
  the full browser/build suite for every commit.
- Added strict i18n coverage for intentionally identical English/French values,
  moved calendar and preview copy into both catalogs, and removed duplicate
  publication terminology.
- Added a shared translated query error state and removed Queue/Calendar silent
  data fallbacks. Added touch-visible media viewer navigation controls.
- Forced Playwright to use one worker because all browser specs share one
  isolated API/database runtime; the prior local parallel default allowed tests
  to overwrite instance and project context for one another.
- Revalidated the user SSE session on every pull and added a focused revocation
  test. Existing project stream access revalidation remains in place.
- Translated historical Autonomos artifacts and isolated worklog labels to
  English, corrected the worker sandbox record to `OPS-151`, and documented the
  missing provider packages plus LinkedIn organization support in `README.md`.
