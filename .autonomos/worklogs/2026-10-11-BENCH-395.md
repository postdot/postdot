# BENCH-395 — AMD64 container baseline

## Delivered

Built the tracked production source from `da39d1063` in an isolated archive context.
Measured three independent fresh SQLite/local-media containers, each before and
following one administrator and project creation. No shared application data,
provider calls, registry publication or GitHub workflow execution.

The report and raw samples are retained in `.autonomos/archive/root-documentation-2026-10-25/source/docs/benchmarks`. Result: 179.7 MiB
uncompressed image; 71.5 MiB gzip Docker-save archive estimate; configured median
working set 100.4 MiB, Bun RSS 143.0 MiB, idle CPU 0.149% of one core. Startup
0.85–1.29 seconds, warm host image caches with fresh databases. Image transfer and
host operating-system memory are excluded. No throughput claim or minimum RAM.

## Method and validation

Ten-second settling period followed by twenty seconds of direct host process and
cgroup sampling per phase. Docker health checks and server maintenance remain
active. This avoids sampling processes inside the measured cgroup. No browser,
SSE, media processing or publication jobs during the idle window. All three final
runs stopped with exit 0 and disposable containers/data were removed.

Temporary measurement harness initially had an origin configuration error, a
cleanup attempt against the bind-mount root, and a Python module-name collision.
Corrected these harness defects; discarded incomplete attempts and retained only
three complete final runs. The production application was not changed.

Verified raw samples and report arithmetic; documentation spelling, whitespace
and commit static gates. No unit/browser matrix warranted by evidence-only files.
Temporary image and archive context removed; the unrelated quoted cache untouched.
