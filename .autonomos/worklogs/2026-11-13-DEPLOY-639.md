the immutable image before creating its GitHub Release. Operator instructions
cover download, verification and Cloudflare staging without a frontend build.

second Studio independently. Check OCI labels and packaged API identity against
the selected version/revision. Preserve notices and record all payload hashes.

remains inside the existing explicit release workflow, with its own outcome in
the summary. Cloudflare verifies identity, inventory and hashes before replacing
staging, and resolves input aliases before checking directory overlap.
