# MEDIA-181 — Define the first safe set of external media sources

- Status: In progress (source registry and URL import slice)
- Branch: `codex/reui-calendar-spike`
- Owner: orchestrator
- Related issue: [ISSUE-103](../ISSUES.md#issue-103-define-safe-external-media-sources-for-the-project-library)
- Predecessor: MEDIA-180

## Objective

Make external media intake an explicit capability instead of exposing provider
buttons before Postbot has decided who authenticates, downloads, and verifies
the bytes.

## Decisions implemented in this slice

- The source registry is Postbot-owned and explicit. It contains the local
  device source, a browser-owned webcam source, and a server-transferred URL
  source.
- The local device and webcam sources stay browser-owned. Device files and
  captured webcam frames both enter the headless Uppy Core/React pipeline. The
  URL source is server-owned and is only exposed by the API when its importer
  is configured.
- URL downloads use the existing controlled network requester, manual
  redirects, per-hop URL validation, the operator private-destination policy,
  bounded response bytes, and a request timeout. Public HTTP remains subject
  to the same egress policy as other server requests.
- Content type, declared size, actual buffered size, and empty responses are
  checked before Postbot reserves an upload. Accepted bytes then go through the
  same reserve → upload → finalize/verification lifecycle as local files.
- The source picker is Postbot-owned and localized. It does not install Uppy
  Dashboard, Uppy’s remote-source preset, or any provider OAuth integration.

## Delivered

- Added the shared media import source registry and API/client response types.
- Added the authenticated source discovery endpoint, omitting unconfigured
  sources from its response.
- Added a server-controlled URL importer with redirect, network, type, size,
  and binary-preservation tests.
- Added a compact source picker dialog and connected it to the Media library
  and publication attachment import entry points.
- Added localized URL-import diagnostics in English and French.
- Added a Postbot-owned webcam dialog that requests camera access only after the
  user chooses Webcam, captures a JPEG locally, stops tracks on close, and
  sends the resulting File through the same Uppy restrictions and upload
  lifecycle.
