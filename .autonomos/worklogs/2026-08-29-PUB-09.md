## Key decisions

- No additional local code change was justified after the audit; adding a second
  smoke path or a provider-specific shortcut would duplicate the dashboard/API
  contract and increase the risk of testing a path that operators will not use.
- PUB-09 remains in progress because the required live provider request has not been
  made. The local environment has no LinkedIn client credentials, and a real post
  must use an operator-owned test account with explicit test content.
- ADR-011 remains `proposed`; implementation completion and documentation do not
  silently accept a project decision.
