# WEB-119 — Web route state contract draft

- Date: 2026-09-08
- Status: in progress
- Scope: empty, loading, populated, partial, failed, recovery, and realtime
  states for authenticated web routes
- Evidence: SPEC-006, ISSUE-063, ISSUE-064, current route implementation, and
  the Muse-1.3/Luna-max audit reports

## Findings carried forward

- The current audit evidence is strongest for the empty project and cannot
  validate the hierarchy once multiple channels, publications, failures, and
  notifications are present.
- Calendar currently hides its desktop date grid when no publication is
  scheduled, which violates the proposed date-oriented entry contract.
- Compose must preserve input across missing-channel, validation, and server
  failure states.
- Queue, notifications, and Overview must update through the existing realtime
  boundary without resetting unrelated user context.
- Global provider settings require an explicit instance scope independent of the
  selected project.

## Result

Created [SPEC-007](../specs/SPEC-007-web-route-state-contracts.md) as a draft
state contract. It is deliberately behavior-oriented and does not prescribe
the final component tree or copy. WEB-119 remains in progress until the state
matrix is reviewed against representative fixtures and accepted for
implementation.
