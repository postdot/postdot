## Full-gate regression finding

The narrow composer journey exposed a real navigation defect: the persistent
project selector kept its popup open after its configuration link navigated.
Moving the return into the page made that overlay intercept the return action.
Configuration links now explicitly close both project and workspace selectors;
the narrow journey asserts popup dismissal before returning. This preserves
search and configuration capabilities and fixes the obstruction rather than
forcing a click through the overlay or weakening the test.

The same run also exposed an E2E fixture cleanup race in the media-only review:
removing the editor interception while its fetch was still running caused
`Route is already handled`. Cleanup now waits for active route handlers before
removal. Publication/media assertions remain unchanged. The final gate is run
against a stationary source tree after these fixes.
