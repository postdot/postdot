# UX-657 Composer: labelled channels, honest preview, safe schedule, silent restore

- Outcome: The channel strip shows labelled chips (mark and name), an explicit "All channels" chip, a visible pressed state for what the editor edits, in-chip removal, available channels as dashed chips and "New channel…" last (P1–P3). The writing area has a surface (P4). Previews speak as the channel: the sample persona, portrait and invented engagement are removed from the provider contract, and the LinkedIn-style card follows the dark theme (P5). One counter for the strictest limit, shown only when it can matter, never "graphemes" (P6). New drafts default to a round hour at least one hour ahead, the date picker never proposes a past time on today and starts weeks on Monday (P7). An interrupted composition is restored silently with a "Start over" notice instead of a blocking dialog (P9). The composer uses the shared left-aligned header without a return control.
- Decisions: ADR-103 §2, §6, §8 applied. Tags row (P8) left as is: it was shaped by an explicit owner request (GH #39, UX-646); revisit only with the owner. "Delivery" single-option select and the manual fallback explanation (rest of P7), P10–P14 move to UX-659/660.
- Validation: `bun run check:quick` passed; unit tests for the counter and date formatting; composer specs run against the production build and, for legacy-editor specs (`?editor=legacy` is dev-only), against the dev server.
- Lesson: specs that open `?editor=legacy` only exercise the legacy textarea in dev mode; a production-build run reports them as failing for that reason alone.
