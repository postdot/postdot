# TELEGRAM-502 — Studio integration

## Outcome

Added Telegram channel creation and the project connection API client, wired through dashboard context and the connection panel. The shared dialog validates the destination and token shape, keeps failures inside the dialog, masks the token and clears it on dismissal. Verification does not send a message.

The real shared editor now projects the supported Telegram execution revision into a conservative UTF-16 counter: 4096 units for text, 1024 when media is attached. Preview and publication target fields use the same projection. Existing text is preserved when the media limit becomes smaller. Native presentation follows explicit execution metadata, not profile names. Telegram uses the official brand icon and generic preview rather than invented client chrome.
