## Implemented presentation

- Match notification kind and complete canonical copy before localization. This
  distinguishes ordinary delivery from reconciled outcomes and leaves unknown
  integration messages untouched. No API or stored event changes.
- Standard success uses one concise title. Failure, uncertainty, and reconciliation
  retain meaningful consequence text. Timestamp and read/archive actions share a
  secondary wrapping row; project names appear only outside the selected scope.
- Replace the invalid article/listitem pairing with native list semantics.
- Localize bound built-in profile labels by semantic meaning, while preserving
  explicit schema titles, custom origins, payload keys, and field values. Locale
  is included in the editor metadata memo dependencies.
- Use DayPicker's complete English/French locales through the shared Calendar
  export. Date labels, month/year selectors, navigation and selected/today states
  now use the same locale. Raise weekday-label contrast without adding decoration.
- Pass the translated navigation title into the mobile drawer; omit its redundant
  generic description. The shared toggle's hidden text follows its supplied name.
- Replace remaining owned French provider terminology with platform or OAuth
  application terminology; substitution names and platform identifiers remain.
