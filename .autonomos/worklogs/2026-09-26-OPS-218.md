- Scope: Extend the isolated production-image acceptance test to verify the dashboard shell and its built assets

## Changes

- Added a reusable HTTP verifier for the production dashboard entry point. It
  requires an HTML response containing Postbot's title and application root,
  collects unique same-origin `/assets/` references from the shell, and requests
  every referenced asset.
- The verifier checks successful HTTP responses, non-empty bodies, JavaScript
  and stylesheet content types, and requires both script and stylesheet output.
  A missing static asset therefore fails even if the SPA fallback could return
  HTML for browser routes.
- The existing production recovery acceptance command now runs this check after
  readiness for both the source and restored containers. CI already runs that
  command, so the existing workflow gained coverage without another build job.
- Kept the failure report tied to container state and recent logs so a broken
  image gives useful diagnosis.
