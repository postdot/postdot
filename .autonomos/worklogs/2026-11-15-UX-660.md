## Slice 2 — Media library entry points and empty-state controls (audit M1 & M3)

- Outcome (slice 2, audit M1 & M3): The Media library header action is now a split `ButtonGroup` whose primary `Import` button opens the native file picker directly, with `"From a URL…"` (`MediaUrlImportDialog`) and `"Take a photo…"` (`MediaWebcamDialog`) in the attached dropdown menu. The permanent `MediaDropHint` ("Drop files or Browse") block is removed; dropping files anywhere on the Media library page uploads them via `window` drag/drop listeners and displays one quiet full-page drop overlay ("Drop files to upload" on a dimmed backdrop) only while dragging files over the page. When the library is empty (no assets and no active search or filter), the toolbar (Search, filter selects, sort, `Select` mode, view switcher, and `Trash`) is hidden and the single shared `EmptyState` offers `Import` to open the file picker.
- Decisions: Kept `MediaSourcePickerDialog` solely for the composer's media attachment picker (`compact` and non-library attachment mode), leaving the composer untouched. When the library is empty while `trashCount > 0`, kept `Trash` reachable on its own right-aligned row above `EmptyState` so trashed assets remain recoverable or permanently deletable. Added `border-r-0 focus-visible:border-r` on the primary split button so `Button`'s `bg-clip-padding` transparent border leaves no 1 px gap beside `ButtonGroupSeparator`.
