## Scope and evidence

Official Mastodon GET /api/v1/statuses/:id is public for public statuses; private status reading requires a user token with read:statuses. This slice is anonymous public reading only, with no scope escalation or credential transport. Retained original-instance permalink plus local status ID identifies the status, as in the existing comment reader. Read only favourites_count, reblogs_count and replies_count; these are provider observations, not reach, impressions or cross-provider totals. Missing values remain unknown, malformed counters remain invalid and real zero stays zero.

Sources: https://docs.joinmastodon.org/methods/statuses/#get and https://docs.joinmastodon.org/entities/Status/

Existing observation storage and latest-per-publication reads support arbitrary provider names; no schema migration is needed. Collection is one explicit editor action for a native published Mastodon publication, and existing project members can read persisted observations. Browsing never calls the provider. Parent injects the existing network-controlled fetcher; no request accepts an arbitrary caller-supplied endpoint.
