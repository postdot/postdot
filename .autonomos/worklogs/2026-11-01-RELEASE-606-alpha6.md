- Denied settings routes return to the resolved accessible project, or explicit
  no-project workspace context, preserving SPEC-010 NAV-01 without granting access.

  text before live access removal and prove direct writes are refused; first-channel
  setup in an empty Queue; the visible Queue return on publication errors; and the
  publication navigation link with viewer actions still absent.
- Candidate/release workflows and the upgrade script now default to immutable alpha.5.

format/lint/spelling/type checks and the production build passed. The default
