## Integration regression corrected

Integration CI's third browser shard failed the lost-promotion-response scenario
at the Saved status assertion; the other completed shards passed. Three ordinary
local repetitions passed, so retrying alone was insufficient evidence. The test
now forces an editor refresh after server acceptance while holding the promotion
response, waits for its rendering, then drops the response. That controlled order
reproduced the original failure before the production correction.

The editor now defers incoming background snapshots while explicit promotion
reconciliation is required, as it already does during an active mutation. This
preserves local content/schedule and the saved-draft status until Check server
status reads the authoritative outcome. It neither repeats the promotion nor
changes permission checks. Both rejected/lost-response scenarios passed after the
fix; the full publication-concurrent-editing file passed all 11 scenarios.

The runtime change supersedes the earlier candidate source for release purposes.
Relaunch push CI and native candidate qualification for the new implementation
commit, with unchanged alpha.6 version and immutable alpha.5 baseline. Earlier
native successes remain evidence for their recorded source only. No image published.
