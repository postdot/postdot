## Implementation

- Added the shared `ChannelProfilePreset` contract. A preset contains a stable
  identifier, version, and provider-owned profile definition.
- Added an API composition catalog for the shipped manual, LinkedIn, Bluesky,
  Mastodon, Discord, DEV.to, and X profiles, plus an authenticated
  `GET /api/channel-profile-presets` route and typed client access.
- Centralized built-in profile resolution behind the same catalog without
  moving provider definitions out of their packages.
- Extended the custom-channel creation dialog to load the catalog through
  React Query. Built-in profiles are shown as human-readable starter options;
  manual and webhook starters remain available.
- Selecting a built-in starter deep-copies its schema, bindings, capabilities,
  and execution mapping, then assigns a custom identity. The copy is completed
  with the runtime JSON-Schema dialect and bounded defaults for provider string
  fields that are intentionally omitted from static provider schemas, so it is
  valid at the custom-profile boundary without changing provider contracts. The
  resulting JSON is editable and has no live reference to the preset, so future
  provider changes cannot silently mutate an existing channel profile.
- Added English/French labels and descriptions, API/OpenAPI coverage, client
  typing, and unit tests for independent snapshots and preserved provider
  execution mappings.
