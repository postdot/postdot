# DEPLOY-638 Optional Cloudflare Studio recipe

Outcome: The existing SPA has a runnable Cloudflare static-assets/proxy recipe,
protected origin snippet and operator guide. ADR-101 records the assessment,
including why this requirement does not justify migrating Studio to Start.

Decisions: Origin IP ranges cannot authenticate an operator's Worker, so the
dedicated origin authenticates a separate ingress secret before relaying client
identity. User sessions and authorization remain API-owned. Preserve redirects
without following them, separate cookies, private cache directives and streams.
The pinned runtime refuses the current date; qualify its supported 2026-10-26
date explicitly. Its blanket SPA fallback returned HTML for missing scripts, so
use an explicit HTML-navigation fallback. Local Wrangler must listen on HTTPS
to avoid Origin/Location scheme rewriting. Generated bindings stay module-scoped
instead of imposing Worker settings on unrelated Node process environments.

Validation:
- Frozen dependency install; format/lint/spelling/types and locale coverage → pass.
- Full unit/scripts → 1,920 passed; 11 existing opt-in skips.
- Production API/Studio through local workerd and Nginx 1.31.8 → final journey
  passed: ingress-secret refusal, API/OAuth navigation, missing assets, browser
  login, rejected origin, private media, 2 MiB upload, SSE disconnect/reconnect,
  remote revocation and scheduled delivery to a controlled local receiver.
- Existing separate-Studio HTTPS/Vite journey → passed after test-proxy extension.
- Production build → all 22 packages pass; docs 265 pages, 1,315 local targets,
  zero broken links. Markdown/LLM and social exports pass.
- Wrangler dry run → 286 asset files, Worker 4.53 KiB / 1.69 KiB gzip.
- Footprint → unchanged API 5,765,376 bytes and initial JS 167,828 gzip bytes;
  maximum sampled idle memory 139,940 KiB, within the existing target.

Open: No hosted account/domain deployment occurred. Edge TLS/IP provenance, plan
limits, custom cache rules and deployed rollback remain operator acceptance.
Next recommended lot: versioned Studio archives paired with API releases, so
operators can deploy matching static assets without compiling the repository.
