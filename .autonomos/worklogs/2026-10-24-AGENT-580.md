## Implementation and reasons

Compared pinned official Postiz, Resend and Sentry sources; observations and
application compatibility are in docs/research/agent-skills-comparison.md.
Three independent skills live under skills/, outside developer-installed skills.
The product skill uses a standard-library HTTP helper because the released image
contains no source CLI and installing a developer environment is unnecessary for
API use. Self-hosting includes matching Compose assets and an exclusive private
configuration preparer; diagnostics use local sanitized evidence by default.
No new product CLI, MCP, provider request or real deployment was added.
