# UX-681 Post composition API

Outcome: SPEC-013 composition saves now update the source and listed drafts atomically, with editor responses, conflict IDs, realtime signals and client, Studio wrapper, CLI and MCP parity. The interrupted checkout was inspected and reused without committing there.

Decisions:

- A source conflict identifies every listed publication; a source-only conflict returns an empty ID list. Listing a stale draft acknowledges the checked current source while omitted target content preserves its text.
- Delivery mode remains on the publication and immutable selected target, never the working draft. A changed mode requires the existing move workflow. Schedule remains applied publication state: changed non-null times reschedule scheduled publications and pending jobs together, with existing future-time, running-job and cadence checks. Removing a schedule or scheduling a draft uses existing lifecycle/promotion operations. Non-null schedule input requires dispatch capability; MCP also requires confirmation. Omitted settings are preserved.
- Tags retain their separate, immediate per-publication semantics. Composition does not promote; subsequent promotion failures remain per-channel outcomes for UX-683.
