# DESIGN-29 — Shared Herald UI package

- Date: 2026-08-31
- Status: completed
- Scope: Shared React UI package, Tailwind tokens, Base UI primitive ownership,
  and web application migration
- Related issue: [ISSUE-004](../ISSUES.md)
- Related decision: [ADR-023](../decisions/ADR-023-establish-shared-ui-package.md)

## What was done

- Added the private `@herald/ui` workspace package under `packages/ui`.
- Moved the shared neutral design tokens, Geist font import, dark-mode variant,
  and base styles into the package stylesheet.
- Moved the existing shadcn `base-nova` Button implementation and `cn` utility
  into the shared package without changing their supported variants.
- Added package-local shadcn configuration, public component and utility
  subpath exports, package guidance, and a unit test for class composition.
- Converted `apps/web/src/styles.css` into a small Tailwind entrypoint that
  imports the shared stylesheet and explicitly scans application and package
  source roots.
- Migrated all current web Button imports to `@herald/ui/components/button` and
  removed the obsolete app-local Button and utility files.
- Updated the root README, web guidance, and IDE workspace for the new package.
- Added ADR-023 to make the package ownership and Tailwind source-discovery
  boundary durable.

## Key decisions and why

- Shared UI belongs in one Herald-specific workspace package rather than in the
  web app or in a premature generic published library. This supports a future
  website and documentation surface while keeping product composition local.
- The package owns shared tokens and base styles, but each consuming app owns
  its Tailwind compiler entrypoint and source roots. This avoids hardcoding the
  current web app path into a package that future Herald surfaces should reuse.
- Base UI remains the only primitive layer. No Radix dependency or Radix-only
  API was introduced.
- Direct public subpath imports are used for components so the dependency graph
  remains explicit and future consumers can avoid importing an unnecessary
  package barrel.
