# CHANNEL-493 — Existing simple JSON body properties

## Changes

Added a guarded browser-only projection and targeted editor for existing properties of an object-expression JSON request body. Fixed strings, finite numbers and booleans retain their types; content references select existing schema fields. Null values are displayed without type conversion. Unknown/nested object, array, map and other expressions stay opaque and unchanged.

Integrated the JSON body disclosure into the real mapped-request form and propagated numeric invalidity through its existing parent validity contract. Kept drafts separate from the last valid profile. State keys encode arbitrary property names to avoid inherited object-key collisions. Missing reference values remain visible rather than silently switching to another source. Added property-level rows to the shared active/proposed comparison and English/French copy describing partial scope.

Updated the isolated Storybook contract with literal values, a content reference and a preserved nested object. Updated docs/project/channel-builder.md with current capabilities and limits.
