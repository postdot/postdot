# NOTIFY-127 — User-global notification inbox

- Date: 2026-09-10
- Status: implementation complete
- Scope: replace project-owned in-app notification reading with a user-owned
  inbox while retaining project context as an optional filter

## Product decision

Notifications belong to the signed-in user. A selected project changes the
visible context but not ownership; no selected project shows all projects and
projectless items. Provider-application settings remain instance-scoped and
must preserve the selected project as navigation context.

## Implementation

- Added a user-owned notification projection shape with nullable project scope.
- Added migration `0025_acoustic_sentinel` for recipient user identity,
  projectless records, user preferences, and user-oriented indexes.
- Preserved old rows through the human actor subject mapping and made the
  migration fail closed when an old row cannot be mapped instead of silently
  dropping it.
- Added user inbox, unread count, read/archive, and preference APIs while
  keeping the project routes as a compatibility boundary.
- Updated the dashboard bell to remain available without a project and to show
  project labels for project-scoped items in the global view.
- Kept project realtime invalidation compatible with the new query key. A
  dedicated user-wide stream remains a future optimization.

## Validation

- Full commit gate: format, lint, typecheck, unit/API tests, 12 E2E tests,
  and production build
- Targeted notification, migration, API, and realtime loading/error tests
- `git diff --check`
