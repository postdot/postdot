# WEB-126 — Preserve the active project context in instance settings

- Status: complete
- Scope: authenticated dashboard navigation and instance-settings context
- Base: `ec87bad6`

## Outcome

Instance settings remain instance-owned, but entering them from a project now
preserves the active project as navigation context. The project remains visible
in the selector and header, and a project overview link is available in the
settings sidebar. Opening the settings route directly without a project keeps
the global instance-only presentation.

## Implementation

- Settings links carry the active project id as a route search parameter.
- The dashboard shell resolves that parameter back to the user's project list.
- The settings shell passes the resolved project to navigation presentation only;
  it does not start project realtime data or change provider-application scope.
- The existing instance-settings navigation contract remains intact when no
  project context is supplied.
