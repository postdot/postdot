# WEB-169 — Give Dense Week/Day Slots a Stable Action Header

- Status: Complete
- Branch: `codex/reui-calendar-spike`
- Owner: orchestrator
- Scope: ReUI Week/Day time-grid slot composition
- Related issue: ISSUE-094
- Related decision: ADR-071

## Goal

Keep the create action visible and predictable when several publications share
one time slot, while preserving compact empty slots and the existing distinction
between inspecting a publication and creating a new one.

## Evidence and direction

- The add button is absolutely positioned in the slot corner and sits below
  the higher-z-index event stack.
- A content-driven frame with a small time/action header is the owner's
  proposed direction for dense slots.
- Empty slots must not pay a permanent vertical cost solely for an action that
  appears on hover/focus.

## Plan

1. Render occupied slots as a restrained frame with a compact time/action
   header above the publication stack.
2. Keep the empty-slot hover/focus add affordance compact and ensure parent
   slot clicks still create with the correct date/time.
3. Verify dense stacks, event preview clicks, keyboard focus, pointer hit areas,
   scrolling, and narrow Week/Day layouts.

## Changes

- Occupied Week/Day slots now render a content-driven frame with the local
  start time and create action in a compact header above the publication
  stack.
- Empty slots retain their compact layout and only expose the add action on
  hover/focus; occupied-slot background clicks no longer masquerade as a
  second create affordance.
- The add button is keyboard reachable for occupied slots and retains the
  existing date/time label and composer navigation.
