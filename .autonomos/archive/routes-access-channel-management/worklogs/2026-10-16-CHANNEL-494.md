# CHANNEL-494 — Simple JSON property lifecycle and source selection

## Implementation

Added explicit add/remove/replace operations for simple properties of an existing object-expression JSON body. Enforced uniqueness, domain-compatible names, the 64-property object limit and known content references. Nested expressions cannot be removed or replaced by these controls. Used own-property checks and safe property definition, including keys such as __proto__.

The form exposes five source/type choices: fixed text, number, boolean, null and content field. Changing source intentionally resets the draft value and clears stale input/error state; selecting the same source is a no-op. Creation errors are local and do not overwrite an existing property or invalidate the otherwise unchanged profile. Empty/unavailable creation choices remain disabled.

Extended comparison to show simple property additions/removals and source/type changes. Missing properties use Absent, distinct from null and empty text. Add/remove of the same unsaved property leaves no row. Updated English/French messages and the existing component reference.
