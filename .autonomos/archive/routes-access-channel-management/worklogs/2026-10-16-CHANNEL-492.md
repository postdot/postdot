# CHANNEL-492 — Optional response extraction controls

## Changes

Added optional publication-ID and publication-URL response paths inside the HTTP response disclosure. The inputs use domain-compatible non-root JSON Pointer syntax. Empty input removes the property; invalid local values block profile saving without replacing the last valid definition. No whitespace normalization or coercion changes valid pointer keys.

The targeted-edit adapter preserves the other request/response fields and supports each extraction independently. The comparison renders additions, replacements and removals with Not extracted for absent paths. Expanded English/French labels and renamed the disclosure HTTP response, since it now covers codes and extraction.

Updated the existing component reference. No domain, storage, connection credential or endpoint dispatch behavior changed.
