configured-applications column and exposed a duplicate top-level “New

redundant controls while preserving the form submit/cancel flow and an
accessible name for the applications region.

## Deterministic reactive-state validation

The isolated Playwright spec `e2e/realtime-validation.spec.ts` now covers:

- authenticated SSE construction with credentials, reconnect refresh, a
  publication update, and an explicit resynchronization signal;
- notification loading while the first request is pending;
- notification-preference request failure and recovery through the visible
  “Try again” action.

The notification query explicitly disables implicit retries because the sheet
already exposes a deliberate retry action and the realtime bridge owns refresh
orchestration. The initial loading guard now handles TanStack Query's actual
`undefined` pre-result state instead of only `null`.
