# CHANNEL-482 — Compact rules and bounded dialog scrolling

## Delivered

- Creation and profile editing keep header/footer outside a bounded scrolling
  body. No shared-dialog default changed for unrelated surfaces.
- Manual creation now has identity then content configuration before persistence.
  It copies the current server manual preset into a custom manual profile using
  the existing creation contract; no parallel channel lifecycle was introduced.
  Optional body/title and the server's other defaults remain intact.
- Collapsed text formats, per-file size and content-language configuration;
  removed routine explanatory paragraphs and preview constraint repetition.
- Language is content metadata inherited from source, not an account grouping
  or translation command. Mastodon forwards it to the provider.
- Removed the misleading media-required switch: required array presence does
  not require attachments when its minimum count is zero. The runtime schema
  remains unchanged.

## Browser verification

Created a clearly named manual test channel through the new steps with a
300-character body maximum. Back/forward retained both name and maximum.
Reopening the persisted profile displayed the same limit. No publication sent.

were both 810 px; only its body scrolled (598 px viewport / 1165 px content).
Header top was 37 px and footer bottom 827 px after scrolling the body.
Desktop editing likewise kept outer height/scroll height equal at 686 px while
its 526 px body held 671 px content. Browser viewport was reset.
