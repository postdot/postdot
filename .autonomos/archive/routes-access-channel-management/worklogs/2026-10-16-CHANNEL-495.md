# CHANNEL-495 — Explicit JSON body initialization

## Outcome

Added an explicit Add JSON body action for custom mapped HTTP requests with no own body property. Creation adds an empty object-expression JSON body while preserving every other profile/request field. Defined bodies, including null, undefined, malformed values, form/multipart bodies and root JSON expressions, cannot be overwritten. Repeated creation is rejected.

The existing comparison shows Absent to JSON object even when the new object remains empty. Simple properties subsequently added to that object also appear individually. Unsupported-body conversions do not produce misleading property comparisons.

Added a Without body Storybook scenario using the actual request builder and comparison components. Updated English/French catalogs. No domain, API, persistence or provider contract changed.
