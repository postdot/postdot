## Objective

Exercise one complete worker lifecycle with a bounded product change: dispatch
an implementation worker in an isolated worktree, verify the base and scope,
handle a controlled stale-base condition, review the returned diff, integrate it
serially, run the full repository gate, merge through a pull request, and clean
up all temporary resources.

## Mission contract

- Original allowed write paths: `packages/custom-http/src/contract.ts`,
  `apps/api/src/modules/workflow/worker.ts`, and the directly related workflow
  test file.
- Review-approved scope expansion: `packages/custom-http/src/transport.test.ts`
  was added because the contract change required updating its direct fixture.
- Forbidden paths: `.autonomos/`, root configuration, lockfiles, migrations,
  unrelated packages, generated files, environment files, and credentials.
- Forbidden resources: shared development servers, browsers, default runtime
  ports, shared SQLite/media paths, external providers, and external side
  effects.
- Allowed checks: targeted package-local tests and static checks that do not
  start services or use shared runtime state. The orchestrator owns E2E,
  browser, container, restore, and real-provider validation.
- Acceptance: the opened custom HTTP media contract exposes the verified
  representation checksum, the application reader compares it with the pinned
  revision before delivery, a regression test proves changed same-size bytes
  are rejected, and the worker reports its base commit, changed paths, checks,
  and unresolved concerns.

## Status

The implementation worker was dispatched from `7a8d5040` and committed
`c0b0eb78` after changing only the allowed code and test paths. Its targeted
test and typecheck commands were blocked by missing workspace module links;
format, lint, and diff checks passed. The worker did not install dependencies,
touch secrets, or alter Autonomos artifacts.

The integration branch was intentionally advanced by the orchestrator-only
tracking commit `3fa0dc14`, making the worker branch stale without touching its
allowed code scope. The worker commit was reviewed and cherry-picked as
`fe919a6e` with no conflict.

The first real regression run failed because the worker compared the persisted
checksum but did not hash the bytes returned by storage. The orchestrator
corrected this in `a38b7bbe`: delivery paths now hash the bounded stream before
the provider or custom multipart effect, then reopen it for delivery. The
custom HTTP transport also checks the checksum exposed by its media contract.
Targeted worker/custom HTTP tests and typechecks now pass; the complete
repository hook (format, lint, typecheck, unit tests, E2E, and build) also
passes. Autonomos artifacts remain orchestrator-owned.

The independent Sol-High review returned `accept with changes`. Its required
retry-classification correction is now applied: a custom multipart preflight
read error is retryable because no external request has started, while a pinned
metadata or checksum mismatch remains permanent. Stream cancellation is also
explicit on rejected media and multipart write failures. The review noted a
non-blocking time-of-check/time-of-use gap between verification and reopening;
this remains a follow-up because representation keys are application-owned and
the current lifecycle does not expose conditional storage reads.
