# OPS-16 — Document separate publisher-key recovery with application backups

- Date: 2026-09-03
- Status: completed
- Issue: ISSUE-018
- Scope: production backup and restore documentation
- Branch: `.autonomos/archive/root-documentation-2026-10-25/source/docs/ops-16-publisher-key-recovery`

## What was done

- Added a production recovery section to the root README.
- Documented that a complete recovery requires the application bundle plus the
  separately managed `POSTBOT_PUBLISHER_ENCRYPTION_KEY` and matching key ID.
- Documented backup handling, restore ordering, secret-management requirements,
  bundle sensitivity, and the consequence of losing the original key.
- Clarified that `/health`, `/ready`, and publisher metadata do not prove that an
  encrypted publisher credential can be decrypted.
- Defined a controlled provider operation as the deliberate verification point
  when credential recovery must be proven, with an explicit warning against
  using a live destination only as a restore probe.
- Added the same key-separation warning and a link to the root runbook in the
  database package README.
- Clarified that Better Auth remains limited to Postbot email/password sessions
  and that publisher token material is distinct from the deployment key.

## Key decisions and why

- The deployment key remains outside the backup bundle, SQLite database, source
  control, logs, and command arguments. This preserves the separation required
  by ADR-012 while making the recovery dependency operationally visible.
- The key ID is safe to record as backup metadata because it identifies the
  required key without disclosing the secret.
- No automatic rekey or new maintenance command was added. The existing runtime
  already fails closed when the key or key ID is wrong, and this task is to make
  the operator recovery procedure explicit rather than introduce a new recovery
  mechanism.
- No new ADR or AGENT.md guidance was needed: ADR-012 and the existing database
  guidance already establish the durable policy; this task documents how to
  apply it during recovery.
