# WEB-183 — Consolidate Queue around one filterable publication list

- Date: 2026-09-16
- Status: completed
- Scope: Queue presentation, publication list rows, selection actions, and related i18n/UI primitives.

## Delivered

- Removed the duplicate full-size attention panel and made attention a filter on the shared publication list.
- Kept lifecycle filters together as tabs (`All`, `Needs attention`, `Scheduled`, `Drafts`) and moved delivery mode into a secondary select.
- Preserved manual due-work actions inside the corresponding publication rows, with compact desktop alignment and responsive mobile placement.
- Reworked selection affordances from radio-like circles to square `check-square` indicators and kept bulk actions adjacent and sticky to the list.
- Reduced Queue list decoration to semantic surfaces, spacing, and restrained shadows; removed the unused attention-panel component.
- Hid the persistent sidebar creation CTA on Queue so the page header remains the single contextual creation action.
- Replaced the shared Select checked-state icon with Solar `check-square`.
