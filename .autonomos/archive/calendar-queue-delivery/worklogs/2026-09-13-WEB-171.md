# WEB-171 — Overlay Week/Day Actions In-Cell and Pin the Time Gutter

- Status: Complete
- Branch: `codex/reui-calendar-spike`
- Owner: orchestrator
- Scope: ReUI Week/Day time grid, local shortcut disclosure, and horizontal
  scroll orientation
- Related issue: ISSUE-096
- Related decisions: ADR-071, ADR-072, ADR-073

## Goal

Correct the owner's latest review of the dense Week/Day affordance. The cell
must remain the spatial owner of its publications and its create action; no
external frame, extra padding, or flow-affecting action band should compete
with the content. The toolbar should expose only a small useful subset of
shortcuts, and the time axis must remain readable when the day columns scroll
horizontally.

## Direction

- `+` is a transient action overlay inside the existing cell, visible on
  hover/focus, above the publication stack, and inactive when hidden. Its
  presence does not change the slot's dimensions.
- The view switcher keeps only its local `M`/`W`/`D`/`A` keycaps. The `[`,
  `T`, and `]` keycaps are removed from period navigation; the accessible
  `aria-keyshortcuts` metadata and scoped hotkeys remain.
- `Kbd` is compact and uses `surface-field` with foreground text and no
  shadow-dependent boundary.
- The time gutter and its header intersection are sticky at inline start in
  the Week/Day scroll surface. The existing day header remains sticky on the
  vertical axis.

## Changes

- Removed the external transient frame introduced by WEB-170 and rendered
  `event-calendar-time-slot-add` as an absolutely positioned child of the
  time slot (`end-1`, `top-1`, `z-30`). It transitions from non-interactive,
  transparent state to an active overlay on slot hover/focus-within.
- Kept the publication stack at `z-20` and pointer-enabled only for its event
  targets, so the button owns its own create hit area without changing inspect
  behavior or making an occupied background create a duplicate action.
- Added sticky inline-start positioning and opaque semantic inset surfaces to
  the time gutter cells, all-day label, and header intersection. The latter
  uses the highest local layer so the corner remains legible.
- Removed the three navigation keycap elements and tightened the shared `Kbd`
  geometry from 20px to 16px with a distinct field surface and no control
  shadow.
- Updated the browser assertions to verify in-cell bounds, z-order,
  geometry-neutral hover disclosure, hidden-action hit testing, sticky gutter
  position after horizontal scroll, and the reduced visible shortcut set.
- Reconciled ADR-071/ADR-072 status so the superseded external-frame and
  shortcut decisions no longer conflict with the current owner direction.
