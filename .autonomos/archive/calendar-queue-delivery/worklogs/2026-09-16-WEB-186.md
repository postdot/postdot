# WEB-186 — Make Queue controls responsive and tabular

- Status: Complete
- Branch: `codex/reui-calendar-spike`
- Owner: orchestrator
- Scope: Queue responsive controls, global selection, and publication table header
- Related task: [WEB-186](../../../TASKS.md)

## Objective

Make the Queue's responsive behavior follow the content hierarchy: lifecycle navigation gets its own wrapping surface, secondary filters flow below it, and selection belongs to the publication table rather than the filter controls.

## Delivered

- Removed the horizontal-scroll fallback from the lifecycle tab surface; tabs now wrap within a compact, width-constrained surface.
- Kept delivery and taxonomy filters on a separate wrapping row below the tabs.
- Moved global selection into a real table-header checkbox with indeterminate state and localized Publication, Destination, and Action labels.
- Reused the same checkbox visual and accessible input semantics for row selection.
- Corrected explicit mobile grid placement so row actions stay in the action column instead of being auto-placed before publication content.
- Added responsive and header assertions to the Queue browser contracts.

## Verification

- Targeted responsive Queue, bulk selection, populated-state, and outcome-state browser suites passed: 5 tests passed.
- Full `bun run check` passed, including formatting, lint, typecheck, i18n coverage, builds, and the repository browser suites.
