# WEB-188 — Reframe Queue empty states

- Status: Complete
- Branch: `codex/reui-calendar-spike`
- Owner: orchestrator
- Scope: Queue empty-state composition, illustration, and concise copy
- Related task: [WEB-188](../../../TASKS.md)

## Objective

Replace the Queue's row-like empty result with a recognizable page state: a centered illustration, short contextual copy, and the existing next action, without adding borders or a second list-like hierarchy.

## Plan

- Reuse the shared Base UI `Empty` primitives through a publication-specific composition.
- Provide theme-token SVG artwork that can later be replaced by a supplied Figma illustration without changing the layout contract.
- Omit the redundant draft description while preserving localized fallback copy for other empty Queue filters.
- Cover the illustration and empty-state semantics in the existing browser contracts.

## Delivered

- Replaced the row-like Queue empty result with a centered composition built from the shared Base UI `Empty` primitives.
- Added a reusable `PublicationEmptyState` slot for title, optional description, action, and replaceable illustration content.
- Added a theme-token SVG illustration so one asset remains legible in light and dark themes; it can be replaced by the supplied Figma SVGs later without changing the layout contract.
- Removed the draft-only filler description so the empty draft view contains only its useful title and action.
- Added browser assertions for the empty-state surface, illustration, and removed draft copy while preserving the existing all/attention actions.

## Verification

- Targeted Queue empty-state and responsive browser suites passed: 2 tests passed.
- Full `bun run check` passed, including formatting, lint, typecheck/i18n, unit tests, all 20 browser tests, and builds.
