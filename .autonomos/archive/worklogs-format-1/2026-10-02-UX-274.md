# UX-274 — Account credential dialog

## Outcome

Aligned the password dialog with the existing raised surface and removed the
contrasting footer strip. Added independent password visibility controls using
existing localized labels and Solar eye glyphs. Fields stay masked initially,
retain autocomplete and length constraints, and remain disabled during submission.
Authentication, current-password verification and session consequences are unchanged.

## Implementation and verification

- Updated `apps/web/src/components/user-account-page.tsx` with a local password
  field component; visibility controls are separate buttons with field-specific
  accessible names and pressed state.
- Extended `e2e/account-settings.spec.ts` to check independent masking and
  inspection, including preserved new-password input after a failed submission.
- The focused account journey passed across English/French, light/dark and
  1280/820/390-pixel layouts, including accessibility checks and successful change.
- Inspected fresh isolated dark desktop and light mobile captures. This does not
  claim a live review of the owner's authenticated data.
- An initial browser check caught pointer interception: translating the eye button
  for vertical centering conflicted with the primitive's pressed translation.
  Fixed positioning inside the 40-pixel field avoids that movement conflict;
  ordinary Playwright clicks pass without forced interaction.
- Full `bun run check` passed: format, lint, typing, unit tests, 48 browser
  scenarios, two password recovery scenarios and all 17 build tasks. Both
  development services returned HTTP 200 after validation.

## Decisions and next work

This remains a scoped application correction, not a global surface or button
redesign. Existing guidance already covers hierarchy and primitive reuse, so
AGENT.md is unchanged. UX-275 is next: review notification destination routing,
missing/inaccessible subjects and touch targets. Recommend keeping navigation
separate from explicit read/archive mutations; that behavior is still a proposal.
