# MEDIA-210 — Permanently delete assets from Trash

- Status: Complete
- Branch: `chore/reconcile-autonomos-ledger`
- Related work: MEDIA-182, MEDIA-183, ISSUE-104
- Decision: Allow one-at-a-time permanent deletion from Trash, without adding a bulk empty-Trash action. Require a confirmation that identifies the file and states it cannot be restored. Use the same project-editor authorization as moving media into Trash.
- Safety boundary: The explicit action bypasses the configured recovery delay only after confirmation.
