# UX-264 — Readable dark surface hierarchy

Status: Complete

Owner review identified a near-invisible navigation/page boundary after UX-263.
The root cause was ordering and magnitude: the page was darker than the shell,
and several role values differed only slightly near black. A black shadow could
not provide a useful edge there. Dark page, raised content and overlay now use
ascending values (0.20, 0.255, 0.32), above the 0.135 shell foundation. Fields,
insets and controls retain distinct task roles. Muted text follows the new
hosts with stronger foreground contrast.

A shared shell shadow supplies a single restrained inset edge at the desktop
work-page boundary. The light shell retains its existing subtle shadow. Mobile
full-width pages do not gain a redundant perimeter. Cards remain surface-led.

The token test now checks actual adjacent roles rather than demanding every
role have a unique shade. Main dark layers must retain a deliberate elevation
step. Existing text/link checks and automated browser accessibility thresholds
are unchanged. Numerical checks are not a substitute for human visual review.
Stable composition guidance is saved in packages/ui/AGENT.md and DESIGN.md;
exact palette values remain a reviewable implementation.
