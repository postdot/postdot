# SITE-459 — Exported-link guard and bounded handoff

Added an offline checker for actual exported HTML using Bun's HTMLRewriter. It
resolves relative and root links, verifies local files/downloads and fragment IDs,
and deduplicates destination checks. External URLs are excluded; no server or
network client is used. The focused temporary-fixture test exercises valid encoded
fragments, downloads and relative pages plus missing-page and missing-anchor cases.
The docs build now runs the checker after static export; existing output can be
checked independently with check:links. DOCUMENTATION.md records the boundary.

Validation: utility test passes; the current export has 186 HTML pages and 760
unique local targets with zero failures. Full docs build including the link gate
and repository quick static checks passed. No screenshot needed for a build-only
change; the preceding pass's browser evidence remains the visible deliverable.

and static-link verification (SITE-459). No additional passes were invented to
