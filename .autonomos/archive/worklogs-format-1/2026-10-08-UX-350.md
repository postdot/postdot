# UX-350 — Existing publication tools and execution

Base: `b250aea38`. Diagnostic only; no production changes.

## Method

An isolated browser probe creates nine real channels and one source post with nine
manual-delivery drafts: native X/Discord/DEV.to, renamed custom templates retaining
those native execution contracts, and manual custom profiles with matching IDs.
Custom templates come from the existing creation dialog. The primary-text field
is found through each returned profile binding, not guessed property names.
Every creation and initial compatibility check succeeds.

For every publication, the probe opens the actual destination controls, measures
commands and weighted feedback, edits the body, waits for its successful draft
PATCH, then reads persisted data. It promotes the revision and records a manual
publication through the actual API. No provider call is made. The reloaded locked
view must show the saved text, the correct preview platform and no Bold command;
the selected target must contain the exact saved string. The source body remains
unchanged before and after manual publication.

All nine saved bodies equal `Exact saved <kind>-<platform>` byte-for-byte. All
nine selected targets retain that body after manual publication; source body
`Initial source text` is unchanged. Locked views render that body with the expected
native or generic platform and no rich commands. No data-loss defect is established.

## Fixture corrections

The first attempt used Date.now() for promotion. Network transit made it a past
time, correctly rejected with invalid_time. The probe now schedules one second
in the future and waits for the actual wall clock before manual publication.
No server guard is bypassed.

The second attempt replaced an initially bold passage through contenteditable
fill and expected plain serialization. The native Discord editor retained the
initial bold mark and saved a correctly marked Markdown string. That was an
invalid fixture expectation, not a demonstrated editor defect. The final fixture
starts with plain text so it measures an unambiguous plain replacement. Complex
Markdown round-trip fidelity is not claimed by this probe.
