# ONBOARD-582 — Installation and first-administrator onboarding

## Scope and result

Reviewed all seven open GitHub issues (#5–#11). Implemented the bounded
installation/first-run corrections in #5, #6 and #7. No production instance,
provider connection, deployed database or release tag was changed.

- #5: maintenance help now precedes configuration, storage access and interactive
  prompts, including in the production entrypoint. Both help flags cover backup,
  restore, recovery, media-previews and account recovery. Operational behavior
  without help is unchanged.
- #6: the setup form explains administrator powers and public signup closure in
  English and French through its existing description slot. Invitation/signup
  policy and initial navigation are unchanged.
- #7: the canonical installation guide downloads Compose/configuration files from
  the published image's exact source. A source build has separate full-checkout
  instructions. The S3 example includes every supported setting and explains
  storage identity, endpoint reachability, persistence and migration limits.
  The release maturity appears as version metadata within the ordinary workflow.
- Corrected the managed Turborepo guidance's package-local `docs/README.md` path;
  the preceding root-documentation migration had incorrectly rewritten this
  generic package path as a project archive path.
