# UX-365 — First-publication continuity

Base: `7421f719f`. Status: complete.

## Outcome and rationale

The empty Overview previously sent its create action to Channels, and the new
publication route redirected to Channels when no active destination existed.
Creating a channel there did not return to the original authoring intent.
The empty composer rail also ignored its existing creation callback.

The first-publication entry now opens the composer directly. An owner or editor
can write source content and use the existing channel dialog in place. The
first destination fills the existing empty target slot through the unchanged
context callback. Canceling the dialog leaves the text and route intact.
Scheduling controls stay absent until there is a selected destination; publication
submission already required one. The first-channel trigger has a visible label;
subsequent creation retains the existing compact toolbar action.

Viewer navigation, connection contracts, manual defaults, OAuth callbacks,
server validation and publication execution are unchanged. Connection remains
optional for manual delivery and required for automatic delivery. No provider
credential or external delivery was needed for this pass.

## Scope and evidence

Changed: new route, composer page and destination rail, empty Overview action,
EN/FR copy, existing authoring spec and three empty-state assertions.
A real isolated account/project scenario covers the empty entry, writing before
channel creation, cancellation, creation/selection, publication creation, Queue
navigation and persisted source text. Mobile screenshots were inspected at
390px. The populated French live composer was inspected without editing its data.

The first targeted run used a link locator for a Base UI button-rendered link;
the second used an input-value assertion for rich text. Corrected the locators
without modifying application behavior or adding timing workarounds.

The selector retained 20/39 scenario files, exceeding half the matrix; one full
control was therefore required. Explicit changed paths exclude the preexisting
untracked quoted cache directory, which is unrelated and preserved. The full
run passed static checks, all units and 101/104 standard scenarios in 21.5 min.
Three failures expected the obsolete Add channel empty-Overview action. Their
assertions now require New publication (and its actual link count); they are
rerun alone. No app code changed after the full run. Validation is assembled,
not a claim that the original full command returned zero. Remaining SMTP and
build stages run separately; no second full matrix or container acceptance.
