# SITE-452 — Hero Studio tour

## Changes

Consolidated Compose, Queue and Calendar into a three-view hero tour. Removed the
separate planning screenshot chapter and its unused imports/helper. Footer tour
navigation targets #studio-tour; the following networks rail provides #networks
for a direct skip link.

Desktop uses a short CSS sticky figure within 184svh of native document scroll.
Motion observes progress to select existing screenshots; no wheel cancellation,
scroll lock or timer. Same-size image layers fade while frame geometry stays fixed.
Manual native buttons navigate the same progress intervals and retain focus.
Each view has one short caption on a neutral, attached surface for contrast.

Mobile, short viewports and reduced motion use a natural horizontal snap strip
without added document height. Buttons and gestures select views; reduced motion
uses instant selection. Crossing into manual mode resets strip and caption together.
First image remains high-priority; others reuse existing lazy WebP assets. Capped
material canvas height as well as width to avoid excess resolution in the taller
hero. Fixed-size grain remains unchanged.
