retained in preview dialogs; detail crops remove irrelevant blank space and shell.

primitive, real product view tabs with stable height, zoom previews with keyboard dismissal

permission context, and practical questions using Fumadocs' Base UI accordion.
Provider marks use the existing Iconify logo distribution. Normal-sized owner
mark only, experimental split wordmark retained. Header reused on 404/error UI.

Updated the public metadata and narrative candidate. Fresh visits start light to
match the owner's references; saved preferences and manual dark mode remain.

Motion uses product perspective, scene entrance and a small poster rotation;
reduced motion retains visible content and native scrolling.
