## Proof and measurement

Twelve deterministic cases cover exact ownership and scenario unions, retention
of the directly changed connection journey in UX-341, and full fallback when a
known fixture accompanies an unknown story/helper or existing transversal file.

domain name and treated a shared UI component as transversal, although the
existing selector maps it to shell tests; these assumptions were corrected,
without changing that established policy. TypeScript union narrowing was also
added to the test assertions before full validation.

The original selector at the base commit reports all 39 standard spec files for
the three executable paths changed in UX-341. The corrected selector reports nine
files: the eight authoring journeys plus the directly modified connection journey.
That is 30 fewer files (about 77 percent). No browser-time saving is inferred from
file count; the selected files have unequal costs. The prior implementation was
probed outside the repository, with only its repository-root location adjusted;
the temporary file was deleted.
