# SITE-413 — Public recovery pages

## Scope

The owner accepted SITE-412 as a stronger foundation, with later detail reviews,
and authorized the proposed 404/error continuation before competitor research.
Preserve that visual vocabulary instead of starting another direction study.

## Implementation

The shared recovery component now has a two-column desktop composition, a routed
blue graphic using the existing visual material, and a stacked mobile layout.
Missing pages offer a primary home action and a documentation link. Load failures
preserve the actual Next error-boundary reset callback as their primary retry
operation; home becomes secondary. Decorative status artwork is hidden from
assistive technology. Only the route drawing animates, and reduced motion removes
its duration. No artificial loading timer or animation blocks recovery.

Extract the existing footer into `PublicFooter`, shared by the homepage and
recovery pages. Its content, links and brand geometry are unchanged. The existing
compact header is reused. No application, authentication or publication behaviour
changed, and no preview/error-debug route was added to the static export.

## Verification

Docs formatting, lint, typechecking and static export passed. The actual exported
404 returned HTTP 404. Browser inspection covered dark desktop and light 390 px
mobile; no horizontal overflow was observed. Documentation and home navigation
worked. The site preview was not running at the start of visual review; restarted
it on its existing local port 5174. Application and API processes were left alone.
A stale failed browser tab could not be rebound because its generated data URL was
blocked; a fresh normal HTTP tab was used after the server was available.

The load-failure variant compiles and retains the framework reset wiring. A real
runtime exception was not deliberately introduced into the shipped site, so a
browser recovery from an actual thrown exception was not exercised. No whole-app
E2E suite or new duplicate visual test was required for this presentation change.
