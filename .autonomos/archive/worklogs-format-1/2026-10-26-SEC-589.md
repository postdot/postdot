to 10.6.2. Both shared-UI and web manifests are aligned; the lockfile contains no
remaining 10.6.1 Storybook package. No unrelated dependency upgrade was requested.

and repository Dependabot alert #19 identify 10.6.2 as patched. The affected path
is a running development server opened in a browser, not a built Storybook or
the deployed Postdot application. The new origin restrictions remain enabled;
no insecure embedding or messaging feature flag was added.

Validation: the complete Storybook build succeeds with the aligned dependencies;
its installed 10.6.2 CLI passes an isolated localhost smoke test on an allocated
port and exits. Repository format/lint/spelling/typecheck checks pass. No new
implementation-mirroring test, application browser matrix or image publication
was needed for this development-only dependency patch.

The first install exposed a second pinned integration dependency in apps/web;
it was aligned before final build acceptance. No production data or service was
touched. Generated Storybook output remains ignored. No AGENT.md update: the
existing dependency-maintenance policy already covers a concrete patch rationale.
