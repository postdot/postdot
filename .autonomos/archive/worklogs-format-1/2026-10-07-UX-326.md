- Base: `f99676be019210a918a169b25f30b4c92a586554`.
- Scope: channel profile dialog, impact presentation, EN/FR catalogs and the existing channel profile browser spec.
- Status: complete; static, unit and selected browser validation passed.

## Existing contract, now reachable

ADR-020 and the activation transaction already allow an incompatible new channel
profile to become active without rewriting existing content. Activation evaluates
current drafts and pending selected targets, records review requirements and
protects pending delivery. The web button previously prohibited this activation,
preventing the explicit adoption workflow from becoming reachable through the UI.
This pass aligns the entry point with that accepted contract. No store, API,
approval, scheduler, provider or migration rule changes.

The operator reviews impact, chooses Review activation, and confirms in the same
dialog. The confirmation refreshes the assessment and explains that content and
scheduled times remain, incompatible selected versions cannot be delivered and
nothing is automatically adapted. Back returns to the profile without mutation.
The confirmation and result headings receive keyboard focus.

The result uses the assessment returned by the activation transaction, not the
previous preview. Affected publications retain distinct draft and selected-target
consequences and inspection links. Adaptation remains a separate action in the
existing publication editor; it does not select a new execution revision or
resume delivery implicitly.

## Failure and ownership boundaries

- Unsaved JSON cannot be previewed or activated.
- The existing expected draft revision protects activation against another editor.
  An activation failure clears the assessment, prevents another write and offers
  an explicit Reload saved profile action. The JSON remains copyable but cannot
  be edited until the saved state has been read again.
- A successful activation followed by failed project refresh remains a successful
  activation, with a distinct refresh error. It does not offer another activation.
- Existing dialog session generations ignore results after closing or switching
  channels. No polling, timer, new endpoint or automatic retry was introduced.

## Follow-up and crystallization

The profile authoring surface still exposes raw JSON and immutable hashes.
Changing a schema while retaining its hash can fail the existing compiler's
identity guard. A bounded diagnostic should establish which values operators
must author, which can be derived, and whether the current editing path meets
that ownership contract. Do not silently generate new identities or change
version ownership as part of presentation work.

Existing accepted policy is reused; no new global design, architecture or
`AGENT.md` guidance is warranted.
