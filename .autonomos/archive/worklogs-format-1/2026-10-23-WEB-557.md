## Implementation

The prototype route checks Vite's development flag before loading. Production
access redirects to the same project's overview with history replacement.
The experimental React component loads lazily only in development; production
builds eliminate that import and retain only an empty route component behind
the redirect. Project access still uses the existing parent route.

No changes to the actual project realtime provider, shared dashboard context,
client data-layer choice, dependencies or prototype implementation. Keep the
larger structural questions in ISSUE-188 open.

Files: prototype route, ISSUE-188 progress, WEB-557 task and this worklog.
No AGENT.md addition: this local route restriction belongs in its implementation.
