# STUDIO-504 — Compact Telegram connection

## Outcome

Removed the dialog introduction and both always-visible field explanations. The channel placeholder supplies a username and numeric ID example. A single named help button next to the bot-token label opens the necessary BotFather/admin guidance in a shared Base UI popover. Click, touch and keyboard activation are supported; hover is not required. Errors remain visible in the dialog.

The owner reiterated a durable preference: operational forms should be understandable through familiar labels, examples and controls, with exceptional setup help on demand. Updated the existing operational UX skill and linked the rule from apps/web/AGENT.md. This does not prescribe help icons on every field.

## Validation

Browser verified the compact default state and help-button activation and Escape dismissal using the actual connection component in Storybook. No real connection was submitted. Static format/lint/spelling/types and translation coverage checked with check:quick. No domain/provider code changed, so provider tests were not repeated.
