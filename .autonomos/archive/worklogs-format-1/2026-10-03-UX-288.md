# UX-288 — Existing publication media-only authoring controls

## Finding and scope

Existing text-bearing sources already mount media insertion in the shared editor
toolbar. The remaining mismatch was media-only source content: Add text appeared
above the images but media insertion remained below them. Keep the useful compact
media-only composition rather than mounting an empty editor merely for parity.

## Change

Use a compact action row containing Add text and the existing media insertion
portal above the thumbnails. Expanding text replaces this row with the standard
configured/native editor toolbar; the same picker mounts there and retains its
selection. Destination editors remain independent. No source/target ownership,
payload, scheduling, autosave, recovery, validation or media policy is changed.
Read-only sources retain their existing inspection behavior.

control, action-row placement above the images at 1280/390 pixels in both themes,
keyboard opening of the library, preserved attachments and toolbar movement when
text is expanded. The first run used an incorrect library test selector; corrected
to the existing library marker without removing the opening assertion. Focused
journey passes. Captures now switch theme through the actual theme control and
assert the applied theme, instead of modifying a CSS class that the provider can
