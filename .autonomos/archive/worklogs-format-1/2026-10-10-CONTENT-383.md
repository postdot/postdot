## Implementation

- Shared Command wrappers use cmdk 1.1.1 as documented by the official shadcn
  Base UI registry, with Postbot's existing Base UI Dialog (no cmdk Dialog or
  Radix composition). cmdk brings transitive Radix packages in the lockfile;
  Postbot does not use their dialog. Solar Magnifier is confirmed by the catalog.
- `/api/search` is a typed, session-only dashboard read. Current workspace
  projects and actor candidates are intersected with `canAccessProject` on every
  request. Workspace-manager visibility alone does not expose project content.
- Current shared-source headline/title/body and channel/project names are matched
  by literal substring; SQL parameters preserve literal `%`, `_` and quotes.
  SQLite lowercase is ASCII case-insensitive; accent folding, Unicode case
  folding, fuzzy ranking and adaptation search are not claimed. Results are
  sorted by updated time/id and capped at ten per category, with refinement copy.
- No schema migration, provider calls or separate search service. Returned bodies
  are bounded excerpts, not full source documents. UI query changes/close/scope
  changes ignore outstanding responses; a 250ms debounce avoids per-keystroke
  requests, with no polling or automatic retry.
- Localized page labels and aliases make settings discoverable without server
  data indexing. Admin-only entries use existing global/workspace capabilities.
- Keyboard navigation, explicit all/current scope, local error/retry and bounded
  responsive geometry use shared UI primitives. Existing publication operations
  and unsaved-navigation blockers are unchanged.
