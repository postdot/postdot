# SITE-417 — Initial widget state and public recovery presentation

## Scope and result

Owner requested immediate correct theme symbols, no return-control flash at the
page top, review of their existing studio and 404 references, a richer social
footer, and sourced animated material. No publication or purchase authorized.

- Read agency studio's theme provider and CSS-based toggle. Installed its exact
  `@wrksz/themes` 1.1.0 dependency. Local storage keeps static export compatible;
  existing `theme` preference key is preserved. Fumadocs' theme provider is
  disabled and its sidebar control replaced. Its transitive dependency remains.
- Both symbols exist in server HTML; document class selects the visible one
  before React. Dark displays Moon, light displays Sun. Transitions enabled only
  after a click; background/color changes suppressed while symbol motion remains.
- Return control renders nothing initially. Measurement and scroll callbacks read
  actual window position; no visible initial opacity fallback.
- Removed rejected repeating PatternCraft texture and its now-unused notice.
- Viewed all four owner-linked 404s. Tala and the personal portfolio informed
  dominant status typography and recovery hierarchy, without borrowing images,
  diagnostics, clocks or CMS behavior. Interaction-only digit animation adapts
  Motion Primitives; no initial scramble and reduced motion skips it.
- Footer has GitHub and muted inactive X/LinkedIn placeholders. No invented URLs
  or accounts. GitHub remains the current private repository address; recheck at
  publication time.
