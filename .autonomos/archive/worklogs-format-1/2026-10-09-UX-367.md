# UX-367 — Resume composition after connection setup

Base: `098b2e84b`. Status: complete.

## Decision and implementation

OAuth already returns to Channels. The composition's existing local recovery
buffer survives full-page navigation; the project context retains work during
client navigation. A second return-URL or session-storage protocol would duplicate
that durable state and add failure cases without providing a new capability.

Channels now uses a single Resume composition back control when an editor/owner
has recoverable source, destination text or media in the current composition or
its project-scoped recovery buffer. Otherwise its Overview return remains.
The resume label is visible at narrow widths. A successful callback does not also
offer a misleading Create a publication action while that composition exists.
The ordinary empty-composition success action remains. There is no automatic
navigation, recovery bypass, changed OAuth state or provider contract.

The existing modal recovery choice restores the exact work after a page reload;
SPA returns reuse current composition. No new storage, credentials, timers,
endpoint or authentication decision. Unavailable local storage retains the existing
fallback; this pass does not broaden the recovery subsystem to server-only drafts.

## Evidence and validation scope

A scenario in the existing authoring spec uses a real isolated account/project:
no work => Overview return; write => Channels => resume => unchanged text;
full navigation to callback-shaped Channels URLs for authorization_denied and
connected => resume => existing recovery modal => exact source and destination.
The callback results are simulated landing URLs, not actual provider exchanges.
Mobile screenshots at 390px were inspected. No live account or channel mutation.
The first run passed in 13.4 seconds. The static gate found a widened string in
the test's result-key lookup; a const tuple fixed its type without app changes.

The selector retained 13/39 files (30 scenarios). Explicit changed paths exclude
the unrelated preexisting quoted cache directory. This is local targeted
validation: static gates, all units, retained scenarios, web build. No full matrix,
SMTP replay or container recovery is justified by this UI-only change.
