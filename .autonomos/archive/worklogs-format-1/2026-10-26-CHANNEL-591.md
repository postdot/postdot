## Implementation

- Present previous field values using the existing read-only field renderer.
  Matching binding identity and semantic role determine reuse; labels do not.
- Surface unmatched fields and changed schema/editor formats individually. Do not
  suggest an automatic conversion for changed, unsupported or read-only fields.
  The operator can enter the new value or use the existing advanced editor.
- Show path changes explicitly. Copy a previous value only after its reuse action;
  validation under the active profile remains authoritative.
- Replace the raw-first previous-draft disclosure with the read-only field view
  and its existing advanced complete-content disclosure. Unrepresented data
  remains available and the existing immutable adoption snapshot preserves it.
- Retain explicit saved/local previous-copy selection, cancellation, conflict
  refresh, candidate validation and save boundaries.
- Update English/French catalogs and the current channel-profile guide.

No new dependencies, network requests, migration, publisher effects, authorization
rules, or release/image publication. No inference from current implementation
absence was used to discard accepted requirements.
