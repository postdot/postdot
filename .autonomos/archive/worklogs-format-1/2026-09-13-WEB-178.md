## Verification

`bun run --cwd apps/web test`, the focused new-publication and media Playwright
scenarios, and `bun run check` all pass. The full gate reports 66 web unit
tests, 8 script tests, 17 Playwright scenarios, localization coverage at 100%,
and a successful production build. The integrated browser was inspected in
light and dark themes.

## Resolution

The new-publication page now exposes a live preview of the active channel. It
resolves non-blank channel content over shared content, preserves the DEV.to
title/body distinction, renders selected media from the existing picker data,
and stays absent when no channel is available. No API or publication-domain
contract changed.
