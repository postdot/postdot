## Limits and next step

Readiness confirms local application configuration, not remote provider health.
An authorization server can still reject a configured client. Those failures must
remain visible at the action that initiated them. A useful next bounded pass is
to harmonize the remaining provider connection dialogs with that behavior,
starting with Mastodon, rather than expand provider features or preview fidelity.
