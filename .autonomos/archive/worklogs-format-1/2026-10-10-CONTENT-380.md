requires a shared confirmation dialog before cancellation/navigation. Browser
unload uses the router guard. This pass adds no durable local recovery buffer.

failure continuations, including the synchronous signal-to-render interval. The
existing suspended page retains the editor mounted but hidden and disabled. An
already sent server request cannot be retroactively cancelled.
