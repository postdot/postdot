# H-11 — Postdot landing holdout

Archived calibration study for the transition from Postdot's operational
workspace to a public landing page. This is not a Postdot implementation and
does not define the final public proposition.

The two compositions keep the accepted H-10 contract constant:

- Cobalt is a signal for action and relationship, not a page background.
- Neutral surfaces establish zones; lines are reserved for the source-to-target relation and meaningful groupings.
- The product truth remains `Post → Publications → Channels`.
- Automatic and manual delivery remain different, first-class paths.
- The dashboard rail, calendar grid, and contextual operator panel are intentionally absent.

`Dispatch narrative` makes the source-to-destinations relationship the hero
visual. `Publication ledger` uses a more editorial, vertical reading structure
to test whether the same identity can survive a materially different landing
composition.

Open `index.html` through a local static server. The lab switcher is outside
the product frame and exists only to compare the two candidates.

This archived reference is evidence for the direction-transfer method, not a
production page or a mandate to keep either abstract hero. The canonical
project direction lives in the repository root `DESIGN.md`.
