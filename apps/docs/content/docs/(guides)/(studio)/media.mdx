---
title: Media
description: Keep the original. Browse with lightweight previews.
---

Upload files through **Media** or the publication editor. An asset has one library
entry; internal thumbnails are not separate files to manage.

Postbot stores bounded image previews and a compact placeholder. Video posters are
optional and generated in the background. An unavailable poster does not block
the original video from being stored.

The original file remains the publication source. A thumbnail is for display and
is not substituted for the file sent to a provider.

Video support currently targets ready-to-publish H.264 MP4 files, without automatic
transcoding. Storage limits and individual destination requirements still apply.
