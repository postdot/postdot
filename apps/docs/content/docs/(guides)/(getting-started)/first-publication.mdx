---
title: Your first publication
description: Create a draft in Studio, review it and choose when it goes live.
---

Create a short text publication for one channel. You need access to a running
Postdot instance and permission to edit a project. To set up your own instance,
follow [installation](/docs/installation/) first.

This guide uses Studio. To prepare the draft with an agent instead, use the
[CLI walkthrough](/docs/automation/#create-a-draft-for-review) or [MCP guide](/docs/mcp/),
then return to [review your draft](#4-review-in-studio).

<Steps>
<Step>

## Choose a project [#1-create-your-project]

Open Studio and select a project, or create one for the account or brand you
publish for. Keep it selected throughout this guide.

</Step>
<Step>

## Add a channel [#2-connect-a-destination]

Open **Channels**, add a built-in channel and select your network. Follow its
[connection guide](/docs/providers/) and check the connected account.

To try Postdot without connecting a social account, add a manual channel. You can
prepare and schedule the publication in Postdot, then publish it yourself.
For a local automatic connection without a developer application or tunnel,
see [Bluesky](/docs/providers/bluesky/).

</Step>
<Step>

## Save a draft [#3-prepare-a-draft]

Open **New publication**, choose your channel and write a short message. For example:

<Callout title="Example post" icon={false}>
    Our new collection arrives on Friday. Take a look at what we have been working on.
</Callout>

Use a channel that accepts text without media for this first attempt. Check the
destination content, leave the scheduled time empty and save the draft.

</Step>
<Step>

## Review your draft [#4-review-in-studio]

Open **Queue** in the same project and select the draft. Check its text, channel,
connected account and absence of a scheduled time. Edit anything you want to change.

If an agent created the draft, review it here too. If its request timed out, check
Queue before asking it to create the draft again: Postdot may have saved it.

</Step>
<Step>

## Schedule it [#5-choose-when-it-goes-live]

You can leave the draft unscheduled until you are ready. To schedule it, choose
a future time, review the destination and confirm scheduling in Studio. For an
automatic channel, this authorizes Postdot to send the content at that time.

Check the publication in **Queue** or find it on the **Overview** calendar.
After the scheduled time, inspect its delivery result. If delivery failed or the
outcome is uncertain, check the recorded result before retrying.

For a manual channel, publish on the destination yourself, then record the result
in Postdot.

</Step>
</Steps>

To adapt a post for more destinations, read [posts and destinations](/docs/concepts/).
To add files, continue with [images and videos](/docs/media/).
