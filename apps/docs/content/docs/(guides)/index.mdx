Use these guides to work in a Postdot project. If your installation is not ready,
start with [self-hosting](/docs/installation/). Otherwise, open Studio and choose
the task you need.

## Connect your tools

Use the same projects and publications from your agent, terminal or workflows.

- [API and CLI walkthrough](/docs/automation/): create a draft for review.
- [MCP](/docs/mcp/): connect your agent to your instance.
- [n8n](/docs/n8n/): create drafts from workflow inputs.
- [CLI reference](/docs/cli-reference/): commands, options and examples.

## Manage your installation or contribute

[Self-hosting](/docs/self-hosting/) covers deployment, storage, backups and updates.
[Development](/docs/development/) covers integrations and contributions to the code.
