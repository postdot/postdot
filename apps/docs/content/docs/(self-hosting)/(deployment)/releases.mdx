### Changes

- Choose a destination explicitly when creating a channel. Manual channels explain
  human delivery and offer ready-to-use defaults with optional content configuration.
- Inspect missing provider setup from its status and open the configuration path
  appropriate to your installation permissions.
- Understand the first account's administrator role before creating it.
- Read maintenance command help without loading configuration or opening storage.
- Use consistent language detection in development and production builds.
- Download release-matched installation files and configure S3 from a complete example.

### Upgrade from 0.1.0-alpha.1

Native checks on both platforms upgraded a previous-release data set and verified
sign-in, project/channel identities, draft state and byte-identical local media. They
also restored the pre-update backup with the previous executable, verified the
original data and confirmed recovery hold blocks writes. No new database migration
is included in this release.

Follow the [update procedure](/docs/installation/#update-and-rollback), back up
database/media and retain deployment secrets separately. Restore with the matching
previous image if needed; changing the image alone does not reverse migrations or
remote publication effects. Anonymous image retrieval is verified. Version tags
remain immutable, with no `latest` alias.

## 0.1.0-alpha.1

This first public alpha provides Studio, the HTTP API and a source-checkout CLI.
It supports project-owned channels, media, drafts, scheduling, review and durable
publication tracking. Provider-native formats, analytics and conversations have
[different coverage](/docs/providers/provider-capabilities/). MCP and mobile clients are not
shipped. Configuration, contracts and migrations may change.

- Image: `ghcr.io/postdot/postdot:0.1.0-alpha.1`
- Manifest digest: `sha256:690778f5d1af8f4a363406b989e17da8672fc764c6e62f9cca8e1a09c483638e`
- Platforms: Linux AMD64 and ARM64.
- [Matching source](https://github.com/postdot/postdot/tree/99badfb431b95a817c645e716267815925c1f6cc).
- [Publication and native acceptance](https://github.com/postdot/postdot/actions/runs/40126611747).
- [Source integration CI](https://github.com/postdot/postdot/actions/runs/40110416940).

Anonymous manifest retrieval verified the same digest and both platform entries.
No `latest` alias exists. Version tags are immutable; pin the digest when exact
content matters. Use the [installation guide](/docs/installation/) for Compose.

There is no earlier public image, so no previous-release upgrade has been
validated. Back up database/media and preserve deployment secrets separately
before replacing an installation. Image rollback alone cannot reverse migrations.
