## Build an integration

Use the [CLI walkthrough](/docs/automation/) to create a draft that a person can
review in Studio. For direct HTTP integrations, start with the
[API reference](/docs/reference/) and [authentication](/docs/reference/authentication/).

The CLI and API are available today. A dedicated MCP server, packaged agent skills,
a supported n8n integration and a mobile client are not available yet. They should
not be treated as dependencies for a working integration.

## Work on Postbot

[Architecture](/docs/architecture/) introduces the runtime and client boundaries.
[Apps and packages](/docs/packages/) maps those responsibilities to the monorepo.

Installation and day-to-day administration live in [Self-hosting](/docs/self-hosting/).
