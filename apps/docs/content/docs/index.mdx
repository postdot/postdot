Herald brings a shared source post and its destination publications into one
workspace. Adapt the content for each channel, schedule automated delivery, or
track the work you publish manually.

Start with [installation](/docs/installation/), then create your
[first publication](/docs/first-publication/).

## Find your way

- [Posts and destinations](/docs/concepts/) explains what changes together and what stays independent.
- [Provider connections](/docs/providers/) explains channel setup and authorization.
- [Media](/docs/media/) covers original files and lightweight previews.
- [API and CLI](/docs/automation/) introduces access for other clients.
- [Operations](/docs/operations/) covers backups, updates and controlled restoration.

Herald is preparing its first public alpha. Images have not been published yet;
the installation guide currently uses a local source build.
