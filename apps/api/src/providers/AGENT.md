# AGENT: apps/api/src/providers

- **Provider integration ownership:** Keep destination-specific server behavior in `src/providers/<provider>` and protocol mechanics in `packages/<provider>` ([ADR-091](../../../../.autonomos/decisions/ADR-091-static-provider-integration-modules.md)). Shared project services consume explicit policies/adapters; they retain authorization and durable execution orchestration. Static registries compose profiles, runtime factories and exact worker revisions. Publisher renewal must use the shared credential preparation port, including replies and first comments; execution-target expiry is a historical read, not the current credential clock. Bluesky restoration uses the durable session store and SDK request-lock bridge so later implicit refreshes share that boundary. Keep provider routes chained for Elysia inference. A new persisted application identity still needs a reviewed migration for the versioned SQLite CHECK; registration alone cannot expand it.
