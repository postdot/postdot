# Platform preview symbols

Bluesky paths are from Bluesky Social PBC's official social-app repository
(Reply, Repost_Stroke2_Corner2_Rounded, Heart2_Stroke2_Corner0_Rounded and
ArrowShareRight_Stroke2_Corner2_Rounded), retrieved 2026-09-30. The accompanying
MIT license is preserved in LICENSE.bluesky.txt.

Mastodon uses these Google Material Symbols paths in its official repository,
app/javascript/material-icons/400-24px (reply, repeat, star and more_horiz).
The accompanying Apache license is preserved in LICENSE.material.txt.

Sources: https://github.com/bluesky-social/social-app/tree/main/src/components/icons
and https://github.com/mastodon/mastodon/tree/main/app/javascript/material-icons.
Only static draft preview decoration uses these assets. Herald's own interface
continues to use its existing Solar icon system.
