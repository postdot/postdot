# AGENT: apps/web/src/routes

- **Configuration context:** Personal settings and installation administration retain the current page when the workspace selector changes; record the workspace in search parameters and clear the previous project with `projectId=none`. Header context does not grant permissions or turn person-owned settings into workspace-owned state. Keep operational project selection consistent with the established project-navigation contract.
- **Settings return controls:** When a settings page gains its own AccessPageHeader return, update DashboardShell hasPageBack for that destination. The shell must not render a second return beside the workspace/project selectors. Keep the navigation continuity test asserting one unambiguous return.
- **Status presentation:** Do not prepend decorative dots to status labels or
  channel names. Preserve readable state text; calendars may use a thin color rule
  to retain event categorization. Unread indicators and timeline markers have
  distinct meanings and are not interchangeable with decorative status dots.
- **Form copy:** Apply the progressive-help rule in `postdot-operational-ux`: familiar labels and concrete examples first, exceptional setup guidance on demand. Do not turn dialogs into tutorials or add an info icon mechanically to every field.
- **Project feature data:** Keep the project parent limited to navigation identity, channels, connections and membership. Feature reads and mutations belong to their Query hooks; invalidate dormant resources without refetching them. Keep feature Suspense boundaries below the mounted QueryClient provider so initial suspension cannot recreate its cache. Choose the dashboard shell from presented route matches (`useMatches`), not the pending location: the previous outlet must retain its QueryClient provider until navigation commits. Revalidate invalidated feature data on entry before showing an empty state; already visible pages retain their last known data during ordinary background refresh or refusal, until a fresh membership check confirms access loss. Key the authenticated dashboard state by user identity so a revalidated account change recreates its feature caches and composition; renewing the same author must preserve them. Composition has a dedicated project-lifetime session for the composition, channel setup and resume flow, separate from navigation data.
- **Page width (SPEC-010 LAY-02):** width follows a page's job. Work surfaces (calendar, composer, queue, media, performance) use the available width; lists of peer objects use `PageColumn variant="management"` (64 rem) and forms or preferences use `variant="reading"` (36 rem). Keep every block of one page, including archive/delete sections, in the same column, and declare a new route in `e2e/experience/route-registry.ts`.
- **Scope navigation (SPEC-010 NAV-01/NAV-02):** a sidebar destination carries the selected project (`projectId ?? 'none'`); never pass `projectId: 'none'` to drop it unless the destination cannot show one. Empty states lead with the first missing prerequisite (a project with no channel leads with `Add channel`).
